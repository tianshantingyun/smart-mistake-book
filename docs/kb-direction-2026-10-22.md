# KB 方向裁定：批次 17 起的顺序与理由（2026-10-22）

> 用户 2026-10-22 授权：「方向由你决定吧，反正都是要做的，先后问题而已」。本文是据此落定的方向与顺序，
> 依据全部来自批次 14–16 的实跑证据（v18 包、D-3 0.7752、弱章诊断、阻塞矩阵）。

## 0. 一句话

**先解阻、再做"确定能赚"的，最后才动需要跨线的结构手术。** 顺序：
① 解阻与证据补齐 → ② 五项尾款按本文件处置（多数是"登记为终态"而非施工）→ ③ A1 保守别名臂（合规上界 +4，价值有限，但它是包侧最后一颗确定性棋子）→ ④ dense-union（唯一能结构性解决 4 个 absent，跨线，需与他会话协调）→ ⑤ 0.90 结论按 ④ 的结果定。

## 1. 为什么是这个顺序（证据）

- **解阻是硬前置**：`core:data` 的 JVM 测试执行被他线测试源编译错挡住（`FigureGenerationAuditRecorderTest.kt:439 eventsAttemptId`）；零漂移门（device↔JVM 同路对称差必须 0）没有 JVM 镜像就无法判读，**任何检索臂都不可采纳**。在他线修复前做 A1/dense-union 只会产出"不可判读"的包与臂。
- **五项尾款的真实价值**（弱章诊断已证）：29 条融合 MISS 中 **0 条**是内容/绑定缺口、**4 条**别名缺口、**25 条**排序。所以"补内容/建点"对当前指标几乎没有直接收益；这五项的收益是**口径与账目的干净**，不是分数。
- **A1 的合规上界**：材料标题/正文派生（T/C）24 条 → 模拟词面 **+4**；题干式（Q）48 条 → +24 但属"用金标反推索引"，按「评测禁止面向结果」纪律**不得采用**；全包盲目缩短 → 净 −1（16 片段截断）。故 A1 是"低收益、确定性高、可逆"的一步。
- **dense-union 是唯一的结构杠杆**：4 个 absent（镁的化学性质、等和线、活结与死结模型、力的分解）结构上无法被"只重排词面候选"的 dense 救回；把候选域改为「词面 512 ∪ dense top-K」需要改 store/DAO 契约（core/database，他会话区域）并重打 dense 资产。它也是唯一可能把主集推向 0.90 的合规路径（在金标冻结、无第二套评测集的约束下，融合参数不可盲选）。

## 3. 执行顺序（批次 17 起）

1. **解阻与证据**（不需要新裁定；他线修复后立即）：复跑 `:core:data:testDebugUnitTest --rerun` 全量 + `GoldenRetrievalJvmTest` → 补批次15 A2 的全量门证据；等 CI 的 `core/export` serialization 修复后确认 CI 复绿、status commit-back 解冻。
2. **A1 保守别名臂**（装置解除后）：预注册（T/C 24 条、零漂移、三规则）→ `alias_exceptions.csv` 追加 → `rebuild_aliases --write` → 19 标签同窗修正 → `promote`（v19，23 门）→ dense 重打 + 重钉 → 设备+JVM → 零漂移 → 显著性（vs A0）→ 采纳或逐字回滚。**预期**：融合增益 ≤ +4，不足以到 0.90，但把"包侧最后一颗确定性棋子"落定并留下 v19 基线。
3. **dense-union 臂**（跨线协调后）：预注册（候选域=词面 512 ∪ dense top-K，K 写死；返回语义与长度预算不变；零漂移；p95 预算）→ 改 store/DAO + 重打资产 → 设备+JVM → 三规则。**这是 0.90 的最后一条合规路径**；若也不达标，则 0.90 按"已知边界"结案，KB 线转内容/结构深化。
4. **尾款收尾**：19 标签随 v19 落地；91/84/3 冲突/182/2 页的终态或暂缓在登记册与批报中各写一行。

## 4. 不做的事（本方向下明确排除）

- 不再调融合参数（α/z-score/精确加成/RRF 变体）：无第二套评测集时任何选择都是"在 129 条上调参"，违反纪律；RRF 已实测证伪。
- 不采用题干式人工别名（Q 类）：属为评测集打补丁。
- 不改金标、不改命中定义、不改 SQL 形状、不换 FTS5、不上 dense 大档。
- 不为 3 条冲突补材料给期望节点（等同打补丁）。

## 5. 验收口径

- 每一步都必须过：零漂移（同路对称差 0）→ 显著性（20k/seed 0）→ 三采纳规则（主集严格更高 + 24 章逐章不劣 + 负向守卫 CI 上界 ≥0）；不采纳逐字回滚并核验 sha。
- 0.90 的最终结论以 dense-union 臂的实测为准；若未达，按"已知边界 + 保守上界"结案，并在验收文书中同时公布 v18 基准与两次臂的读数。
