# 知识库内容写入规范（新增材料必须遵守）

- 制定日期：2026-09-13
- 依据：对既有 2168 个知识点 / 10356 条材料的实测统计 + 编解码与导入契约源码查证
- 用途：后续所有新增内容（五三精炼、存量补抽）按本规范写入；不遵守会导致导入被拒、运行时不可见或与既有内容重复

## 一、校验链（写错就被拒的地方）

| 层 | 位置 | 硬约束 |

## 二、知识点层规范

### 2.1 层级与命名

```
科（数组字段） → 册 → 章 → 主题 → 子主题 → 知识点     （topic 最深 2 层）
```

| 层 | name 规范 | 说明 |
|---|---|---|
| 册 | `物理必修第一册` / `化学选择性必修1` / `生物学必修1` | 全称；跨册统一 `跨册综合`。全库 23 种，无重复册节点 |
| 章 | **必须等于人教版章名**：`第X章 {章名}` | 章节点只作空壳分组，**不挂知识点** |
| 主题 | 可用教辅专题名（去掉 `专题NN `/`第NN讲 ` 编号） | 挂知识点；仅当"像节名且与节点名互为子串"时才设这一层，否则不包层 |
| 知识点 | 见 2.2 | 挂实际知识点 |

- topic slug 规则：`父slug · 去空格name`，≤80 字符，重名追加 `-2`
- **章名必须与 canonical 一致**。现存 3 处不一致需修：
  - 物理必修三 `第十一十二章 电能与电流` → 拆成 `第十一章 电路及其应用` + `第十二章 电能能量守恒定律与可持续发展`
  - 物理选必三 `第四五章 原子与原子核` → 拆成 `第四章 原子结构和波粒二象性` + `第五章 原子核和核反应`
  - 生物选必1 `第一章 人体的内环境与稳态` → `第一章 内环境与稳态`
- 另有 **33 个 canonical 章缺 L2 章节点**（26 个连同名主题都没有）→ 新增内容落到这些章时，应**先补章节点**再挂主题

### 2.2 知识点命名规范

实测分布：name 长度 min 1 / 中位 8 / p90 16 / **硬上限 24**（`gate.py` 规定 >24 字即判"整句话当名称"）

必须遵守：

1. **不以"的"开头**（全库 0 例）
2. **不写"…的定义/的性质"**（这类仅 1.3%）；直接用概念名（`诱导公式`、`牛顿第二定律`、`氯气`）
3. **方法类用裸方法名**：`配方法`（PROCEDURE）而不是 `用配方法求最值`；现有 81 个动宾长句属临界形态，不模仿
4. 长度 ≤24 字；纯中文 4–8 字最规范
5. 禁用形态：题干/答案标记、只有标题冒号（`定义：`）、通用名词无主语（`性质`）、公式被剥离（含 `（ ）`、`即中`）、含 ★

10 个最规范样例：`函数的单调性`、`函数的奇偶性`、`正弦定理`、`二项式定理`、`牛顿第二定律`、`自由落体运动`、`物质的量`、`氧化还原反应`、`渗透压`、`体温调节`

### 2.3 slug 规范

- 知识点 slug 是**历史标识符**，不是 name 的纯函数；规则：ASCII 转小写，`=`/`(`/`)`/`、`/引号 → `-`，折叠连续 `-`，去首尾 `-`
- 允许字符：汉字、`a-z`、`0-9`、`-`、希腊字母、带圈数字
- 唯一硬约束：科内唯一 + 派生 `stableCode` ≤256 + 无控制字符

### 2.4 kind 判据

| kind | 占比 | 该标什么（真实例） |
|---|---|---|
| CONCEPT | 76.1% | 定义、定理、定律、公式、性质、物质/结构概念（`函数的单调性`、`牛顿第二定律`） |
| PROCEDURE | 10.4% | 可执行的操作程序/方法步骤（`配方法`、`判断抽象函数单调性的方法`） |
| REASONING | 5.6% | 推理、判断、比较、讨论类能力（`判断集合间的关系`） |
| REPRESENTATION | 4.3% | 图象/符号/表格等表征性内容（`常见图像形式`、`图示`） |
| EXPERIMENT | 3.6% | 实验目的/结论/误差/装置/操作（`探索光合作用原理的部分实验`、`实验误差`） |

**现状全空、规范未定。新增一律留空**（假前置会驱动复习排程误导学生，宁缺勿错）。

## 三、材料层规范

### 3.1 字段职责与长度惯例（实测中位）

| 字段 | 职责 | 中位长度 | 写法 |
|---|---|---|---|
| `title` | 检索名 / 唯一身份 | 13 字 | 短语命名式为主。三形态：纯概念命名 79%、`概念：说明` 7%、`方法名：步骤1→步骤2` 13.9% |
| `summaryMarkdown` | 一句话结论（含条件与结论） | 38 字 | 完整单句，以 `。` 收尾 |
| `applicabilityMarkdown` | 题型信号（"什么时候用"） | 17 字 | 短语，如 `集合元素含参数、要求取参数值的题。` |
| `contentMarkdown` | 正文（唯一的教学过程载体） | 110 字 | **1–4 行**；`1. …\n2. …\n3. …` 或 `1. 定义：…` |
| `boundaryMarkdown` | 边界/前提/易错（出题范围硬锚） | 31 字 | 真边界，如 `空集优先讨论…区间端点含不含需由不等式方向决定。` |

- `derivationKind` 恒为 `REVIEWED_SYNTHESIS`
- `sourceLocator` 沿用所属来源的既有粒度，不自创格式
- 字段内引号用中文引号（全库 0 条 ASCII 双引号先例）

### 3.2 type 规范

既有只落 2 种；**但选材优先级最高的两类为 0，边际价值最大**：

| type | 选材优先级 | 现状 | 建议 |
|---|---|---|---|
| `MISCONCEPTION_GUIDE` | 0（最高） | **0 条** | **优先新增**：易错/误区类材料 |
| `WORKED_EXAMPLE` | 1 | **0 条** | 例题类——但本来源政策禁止（见 §5），不加 |
| `METHOD_MODEL` | 2 | 3456 条 | 可执行操作链（判断顺序、列→解→验、配凑步骤） |
| `DERIVATION` | 3 | 0 条 | 可不加 |
| `CONCEPT_EXPLANATION` | 4 | 6900 条 | 定义/原理/判据/机制 |
| `REPRESENTATION_GUIDE` | 5 | 0 条 | 图象/表征类可考虑 |
| `COMPLETE_SOLUTION` | 6 | 0 条 | 本来源政策禁止 |

判据：内容是可执行操作链 → `METHOD_MODEL`；是定义/判据/机制 → `CONCEPT_EXPLANATION`；是易错提醒 → `MISCONCEPTION_GUIDE`（新）。

### 3.3 contentMarkdown 结构模板（择一）

```
1. 定义：…
2. 判据：…
3. 注意：…
```
```
1. 由…列等号（如 A∩B=B→B⊆A）。
2. 解出参数值（可能多个解）。
3. 逐个代回检验，舍去不满足的。
```
```
1. 操作：…
2. 现象：…
3. 结论：…
```
常用标签词（按既有频次）：`条件：`/`原理：`/`方法：`/`定义：`/`步骤：`/`结论：`/`原因：`/`公式：`/`判断：`/`特征：`/`规律：`/`注意：`/`误区：`/`区别：`/`联系：`

### 3.4 boundaryMarkdown 规范

- **必须写成能框住出题范围的真边界**：前提、适用对象、不适用情形、易错点
- 禁用三句通用模板（已占 1528 条，属质量洼地）：`该结论为一般规律归纳…`、`一轮复习结论性要点…`、`适用于教材原型实验与操作类题型…`
- 好样例：`空集优先讨论'是此类题最大失分点；区间端点含不含需由不等式方向决定。`／`等号成立条件必须验证，不成立则最小值达不到。`／`微溶物浓度大时按沉淀处理不拆，稀溶液中可拆。`

## 四、绑定与切分规范

### 4.1 绑定

- **每条材料恰好 1 个 PRIMARY 绑定**（代码允许 1–16，但惯例是 1；多绑不模仿）
- 绑定目标必须：同科 + `granularity=ATOMIC` + `verificationStatus=SOURCE_GROUNDED`
- 绑定 ID 格式：`kb:moe-2025-four-subjects-v1:<subject小写>:atomic:<知识点slug>`
- **只绑已有节点，不新建节点**（新增节点须单独定稿）

### 4.2 绑定正确判据（现行抽样只有 42% 完全一致，必须做实）

1. **材料的首要教学对象 = 该节点**——标题去掉节点词后仍有独立主题的，多半是错绑
2. **type 语义要对上**：`METHOD_MODEL` 必须给该节点的方法步骤；`CONCEPT_EXPLANATION` 必须是该节点的定义/辨析
3. **不用"邻近/类比"代替绑定**（现行误绑主要发生在同章相邻概念：光合作用↔细胞呼吸、电场力做功↔弹力做功）
4. **boundary 能框住该节点**——材料讲得比节点宽（专题综述型）不合格
5. 实操判据：材料首句主语/动作落在节点概念上，标题含节点名或节点名核心词

### 4.3 切分粒度

- **一条材料 = 一个原子节点的一个面**：约 **2–4 步**、正文 **~110 字**、全文实体 **≤200 字**
- 健康粒度样例：`DNA 复制需要引物：DNA 聚合酶不能从头合成`（一个小点一小卡 + 完整可读句）
- **禁止碎片级切分**：不要学现行的表头/单元格级碎片（`影响酶活性的条件·控制自变量` 正文只剩 `自变量：控制自变量；`）
- 应拆而未拆的反例（不要模仿）：`奔驰定理与三角形四心的向量式`（一个材料含奔驰定理 + 四组心的向量式）、`集合交并补的运算与等价条件`（含运算定义/等价条件/德摩根律/容斥原理 4 个独立考点）

### 4.4 每节点的材料数量上限（关键）

运行时约束：**每个节点最多 4 条材料被选中**（`MAX_TEACHING_REFERENCES=4`，同节点同类型第 5 条起**永远不可见**）。

→ 策略：**每个节点最多 4 条高价值材料**。已有 4 条同类型材料时，应写更高优先级类型（`MISCONCEPTION_GUIDE`）或替换旧条，而不是叠加第 5 条同质材料。

### 4.5 去重

- 同一节点已有材料讲同一件事时**不重复入库**；新增应提供**不同的面**（概念 / 方法 / 易错）或**更好的表述**
- 判断重复：节点名核心词相同 + 材料标题去掉修饰后相同 + 正文要点重合

## 五、本来源（五三）的额外边界

- 来源政策：`REFERENCE_ONLY` + `REVIEWED_SYNTHESIS_ONLY` → **`derivationKind` 只能是 `REVIEWED_SYNTHESIS`**
- 因此 **不得产 `WORKED_EXAMPLE` / `COMPLETE_SOLUTION`**（那需 `LICENSED_ADAPTATION` 授权）
- 例题不抽（用户要求 + 上游规则"例题不纳入"）；但**例题解析中陈述的知识与方法结论**按结构化转述提取，归入 `CONCEPT_EXPLANATION` / `METHOD_MODEL` / `MISCONCEPTION_GUIDE`
- 插图不裁切入库，图承载的知识转成文字
- `sourceLocator` 格式：`《2027 5·3 A版 高考总复习 <科> 精讲册》P<页码>`
