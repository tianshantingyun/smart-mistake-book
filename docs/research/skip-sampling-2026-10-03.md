- `AGREE`＝同意机械 SKIP（该块确属题目/答案/广告/版权目录等非知识内容）；
- `FALSE_KILL`（误杀）＝块内**实含可入库的知识材料**（概念、方法步骤、易错点、考点条文等）而被机械判据跳过；

**误杀复核**（工作流行 155–163）：判定员判出的全部误杀候选，交**未参与判定的独立复核员**逐条复读原文复核（不看别人的理由）；`AGREE`＝维持误杀，`DISAGREE`＝推翻。

## 4. 误杀率估计（按层加权，正态近似）

符号：层 `h` 的全量条数 `N_h`，样本判定条数 `n_h`，确认误杀 `k_h`（唯一块口径，`n = Σn_h = 199`，`N = ΣN_h = 107,160`）。

- 点估计（全量误杀率）：`p̂ = Σ_h (N_h / N) · (k_h / n_h)`
- 方差（各层独立、层内二项近似，忽略有限总体校正）：`Var(p̂) = Σ_h (N_h / N)² · p̂_h(1 − p̂_h) / n_h`，`SE = √Var`
- 95% 置信区间：`p̂ ± 1.96 · SE`（正态近似）
- 预计回捞条数：`K̂ = N · p̂`，区间 `N · (p̂ ± 1.96 · SE)`

分层明细：

| 层 | `N_h` | `n_h` | `k_h` | `p̂_h = k_h/n_h` | 贡献 `(N_h/N)·p̂_h` | `K̂_h = N_h·p̂_h` |
|---|---:|---:|---:|---:|---:|---:|
| 题目派生 | 100,758 | 120 | 16 | 13.333% | 0.12537 | ≈ 13,434 |
| 过短 | 2,735 | 30 | 1 | 3.333% | 0.00085 | ≈ 91 |
| 广告 | 2,480 | 20 | 0 | 0 | 0 | 0 |
| 同内容指纹重复 | 1,131 | 20 | 0 | 0 | 0 | 0 |
| 其它 | 56 | 9 | 0 | 0 | 0 | 0 |
| **全量** | **107,160** | **199** | **17** | — | **p̂ = 0.12622 → 12.62%** | **≈ 13,526** |

结果：

- **误杀率 ≈ 12.6%，95% CI ≈ [6.9%, 18.3%]**（`SE = 0.0292`）。
- **若全量回捞，预计回捞 ≈ 1.35 万条，95% CI ≈ [0.74 万, 1.97 万]**（万级；点估计 13,526 条中题目派生层贡献 ≈ 99.3%，过短层 ≈ 91 条）。
- 敏感性：① 逐层加有限总体校正 `(N_h−n_h)/(N_h−1)` 后 `SE = 0.02917`，区间变化 <0.1%，可忽略；② 未判的 1 条（其它层）若计入且为误杀，`K̂` 只 +≈6 条，量级不变。

## 6. 口径与局限

1. **样本量**：200 条（唯一块 199 条判定；1 条重复、1 条漏判，见第 5 条）。分层为小层过采样的设计分层，不是按比例分配。
2. **分层与抽样方式**：按 `note` 前缀 5 层，层内**按行号等距抽（确定性）**，不是简单随机；§4 的 CI 用简单随机 + 独立二项的正态近似计算，未计等距抽可能的序列相关，也未计"行序=按来源文件拼接"的整群效应 → CI 应视为近似（量级参考）。
3. **「误杀」的判定标准（模型单一来源、无人类双复核）**：判定由 4 名模型判定员各判 50 条（单模型、每块一次判定，判官自读块原文并引原句）；误杀候选由另一名未参与判定的模型复核员独立复核（AGREE 17 / 推翻 0）。两层均为模型判定、**无人类双复核** → 本报告的"误杀"是**模型口径下的误杀**（"可入库知识内容"的边界含模型主观性，样本中可见"【点睛】附于解析之后算不算可入库"一类边界情况）。
4. **0 误杀的层 ≠ 绝无误杀**：广告/同内容指纹重复/其它三层样本内 0 误杀，正态近似给其方差为 0（是近似局限，不是"证明无误杀"）；这三层按设计过采样（20/20/10）也只能给粗略约束。
5. **行集异常（实核）**：`skip-verdicts-4.csv` 首行＝`skip-verdicts-3.csv` 末行（`e14aad82a5-1145`，过短，AGREE，两处结论一致）；样本第 200 条 `5f510cdc4a-2033`（其它层，版权/出版信息）无判定。§3.2/§4 一律按**唯一块**计（199），未判行按未观察到处理（影响 ≤约 6 条，见 §4 敏感性）。
6. **层标签噪声**：判定 evidence 显示"广告"层多条实为题目派生块（"京东""限时""CIP""略"等误触广告词），"其它"层多条亦实为题目派生（"定价""CIP""略"误触版权/空白词）。这不改变"该 SKIP"的结论，也不影响误杀率分母（判定问题始终是"该不该被跳过"），但说明机械 `note` 分类本身有假触发，供下游分流参考。
7. **判定对象**：块级文本（含"（扫描页图，视觉转写）"占位块），不含图像与版式；同一文档可拆多块，回捞量级也是"块数"。
8. **回捞未执行**：本轮只出估计与清单；全量回捞要走判定源 + merge + 门（工作流行 342–344 已登记为"未做"）。

## 7. 复现

```bash
# ① 全量点数 + 按 note 前缀分层（应得 107160 与五层计数 100758/2735/2480/1131/56）
python - <<'EOF'
import csv, collections
rows = list(csv.DictReader(open('tools/kb_coverage/tables/mechanical_skips.csv', encoding='utf-8-sig')))
def s(n):
    for p in ('题目派生','过短','广告','同内容指纹重复'):
        if n.startswith(p): return p
    return '其它'
print(len(rows), collections.Counter(s(r['note']) for r in rows))
EOF

# ② 判定计数（唯一块）+ 加权估计
python - <<'EOF'
import csv, collections
def load(p):
    return list(csv.DictReader(open(p, encoding='utf-8-sig')))
N = {'题目派生':100758,'过短':2735,'广告':2480,'同内容指纹重复':1131,'其它':56}
seen = set(); k = collections.Counter(); n = collections.Counter()
for i in range(1,5):
    for x in load(f'build/agent-batch4/skip-verdicts-{i}.csv'):
        if x['chunk_id'] in seen: continue
        seen.add(x['chunk_id']); n[x['stratum']] += 1
        if x['verdict'] == 'FALSE_KILL': k[x['stratum']] += 1
tot = sum(N.values()); p = 0.0; v = 0.0
for h in N:
    if n[h]:
        w = N[h]/tot; ph = k[h]/n[h]
        p += w*ph; v += w*w*ph*(1-ph)/n[h]
se = v**0.5
print('p=%.5f se=%.5f CI=[%.4f,%.4f] K=%.0f CIK=[%.0f,%.0f]' %
      (p, se, p-1.96*se, p+1.96*se, tot*p, tot*(p-1.96*se), tot*(p+1.96*se)))
EOF
```
