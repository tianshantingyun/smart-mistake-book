## 已落地的规则

| 场景 | 原生实现与来源 |
| --- | --- |
| 统一动效层 | `ClaudeMotion.kt` 从 cds-theme.css 移植 Swift/Expand/Enter/Out/Snap 曲线及实际使用的时序。主题实时观察系统 animator_duration_scale，关闭动画时不挂载持续动画，转场立即完成；退出页面注销观察者。 |
| 四栏与二级页面 | 四个根目的地间 120ms 淡入淡出；二级页 180ms、最多 16dp 位移；返回 120～150ms。原 NavHost、回退栈、生命周期和业务回调不替换。 |
| 折叠 | `ClaudeDisclosure` 用 200ms 展开、160ms 收起和 150/120ms 淡入淡出。思考、查阅、图片说明及错题筛选的六处呈现统一消费；不在动画结束时写业务状态。 |
| 按压与选中 | 按钮/发送仍为原 0.95 与 150ms；禁用动画时不缩放。分段滑块使用 Snap120；焦点、输入边框与背景、导航/历史/设置的选中/悬停/按压使用统一轻量反馈。 |
| 卡片与列表 | `ClaudeInteractiveSurface.kt` 接入历史、设置、选题、回答方式、附件菜单、快捷建议与思考/查阅标题。保留原选择/点击命令；交互行至少 48dp，纯只读查阅行保持 24dp，不冒充禁用按钮。错题卡使用统一 12dp 外壳、细边框与焦点/悬停反馈，题图继续外显，收藏仍是独立动作。 |
| 加载与运行 | 实际 Loading 才显示 StatusIndicators 的 105°/2s 骨架扫光，关闭动画时静止。运行消息与思考复用 1.9s 三点，不叠加假进度或改变真实状态。 |
| 图片与弹窗 | 统一 200ms、0.95→1 的弹窗入场。图片的手势坐标、尺寸、源角色、缩放/平移/复位与关闭沿原实现，不增加生成或联网操作。 |
| 复制 | 回复动作条复用现有 `ClaudeCopyButton`：原始正文写入剪贴板后显示结果，2.5s 恢复；重试/停止/复制的既有标签、条件和回调保留。 |

不对历史回复反复播放入场，不对公式/正文施加模糊或持续发光，也不把演示工程的语音、模拟成功、用量仪表加入产品。原生下拉和系统窗口的职责仍由平台管理；没有为了动画另建导航器、任务状态机或 Markdown 解析器。
