## 1. 变更内容（只改「0 框」的解释）

旧口径（v2）只看金标题数与应用题数：单题金标页（`questionCount<2`）应用题数为 0 ⇒ 记「一致」。
它把五种互不相同的事压成同一个 0：模型 PASS、模型弃答、通道整轮拒收、区域被消费侧拒绝、导出缺页。

v3 逐页先分类，再判一致（判定字段只来自导出，不猜）：

| pageClass | 条件 | ①(v3) |
|---|---|---|
| `ACCEPTED_SPLIT` | `outcomeStatus=OK` + `decision=SPLIT` + 2..12 个可用区域 | 题数相等 ⇒ 一致 |
| `SPLIT_UNUSABLE` | `OK` + `SPLIT` 但 0 框（消费侧判不可用） | 不一致（产品未切） |
| `ACCEPTED_NO_SPLIT` | `OK` + `PASS` + 空区域 | 单题金标页 ⇒ 一致；多题页 ⇒ 不一致 |
| `ABSTAIN` | `OK` + `RECAPTURE`/`NEED_MORE_IMAGE` | 一律不一致（ITT），单列 `abstain` |
| `NOT_EVALUABLE_CHANNEL` | `outcomeStatus != OK`、无 `decision`、契约整轮拒收 | 一律不一致（ITT），单列 `notEvaluable` |
| `MISSING_APP` | 导出缺该页 | 不一致（`GATE.md`「缺页就是漏」） |
| `V2_FALLBACK` | **整份导出**没有 `decision`/`outcomeStatus`（历史设备导出） | 回落 v2；单题页计入 `singleQuestionUnverifiedCount`，报告 `caliber="v2-fallback"` |

三句话：

1. 单题页只有「被接受的 PASS（整页一题、无需切分）」记满分；弃答/拒收/缺页不拿分。
2. 多题页仍按题数相等判；`PASS` 把 N 题读成 1 题 ⇒ 不一致。
3. 分母恒为可比金标页数；弃答与通道失败不剔除（剔除会奖励多弃答）。

逐页行另带 `questionCountForMetric`，让「弃答不按 0 框计」在机器报告里可见：
`ACCEPTED_SPLIT=区域数`、`ACCEPTED_NO_SPLIT="none"`、`SPLIT_UNUSABLE=0`、
`ABSTAIN`/`NOT_EVALUABLE_CHANNEL`/`MISSING_APP=null`、`V2_FALLBACK=旧口径框数`。
框集本身仍如实记 `appBoxes`（几何真相，供 ②/③ 用）。

回落只按**整份导出**判定，不按页：判定型导出里缺页没有页记录，若按页回落，缺页会重新被
单题页规则记成一致（假阳性）。设备导出（`export_split_eval.py` 的 SELECT 不含 decision 列）
整份无判定字段 ⇒ 历史读数（v1 4/7）逐字保留。

- ③（切残）分子分母都不受口径影响：弃答/通道失败没有框，不产生碎片；批次 50 仍 1/78。
