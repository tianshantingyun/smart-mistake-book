## 2. 本地算术（2026-09-30 现算；脚本见 §4，可复算）

| 0.15（裁决 13 原值） | 22 | 33 | 41 |

| 0.25 | 12 | 18 | 23 |
| 0.35 | 8 | 12 | 16 |

全对 n=8 时：p̂_J=0.944，Wilson 下界 0.676，宽度 0.324。**早前口头汇报的"ε=0.15 → 28 次"是
粗算，按 Wilson 精确算为 22 次**（本表为准）。

### 2.2 现状成本（EMA 0.32/0.42 + Wald×1.2，p₀=0.5，`LearningProjector`）

- 全对路径：**6 次**独立正确即过 `lowerBound ≥ 0.85`（第 6 次后 p=0.951、lb=0.852）。
- 每 4 次错 1 次：p 的均衡值 ≈ 0.70，**永不达标**（判定对持续出错者极不宽容）。

### 2.3 FSRS 最低成本路径（初错后全 GOOD、r*=0.9、仓库默认参数直接算）

S 轨迹（复习日）：0.212（第 0 天初错）→ 1.891（d1）→ 6.285（d3）→ 17.43（d9）→ **43.96（d26，第 4 次成功复习）**
→ **每题 4 次全对、跨 26 天达到 S ≥ 21 天**。前两次若有协助（判 HARD）则 6 次 / 35 天。
注：r*=0.9 时间隔恒等于 S，故"S ≥ 21 天 ⇔ 下次计划间隔 ≥ 21 天"（与 Anki mature 同义）。

## 3. 裁定结果（2026-09-30，用户）——判据 = E（知识点记忆状态）

**裁决 13 的 ε 部分被本裁定取代**。过程：按裁决 13 要求把小 n 表交用户 → ε=0.15 被否
（"全对 22 次要太多次、效率太低、不符合记忆规律"）→ 用户指示先做外部研究 → 摆出 A/B/C
三形态被要求"还有更好的" → D（每道绑定题间隔 ≥21 天）被否："**但是不应该是看知识点吗**" →
**用户定调**："本来就是把错题分到细化的知识点上，……本质上还是知识点为中心"。

**最终判据（E）**：MASTERED = **知识点自己的记忆状态**（同一套 FSRS 更新吃它的作答流，
零新数学）满足 **稳定度 ≥ 21 天（Anki mature 口径）∧ 当前召回概率 ≥ 0.9**
（等价：距上次作答 ≤ 稳定度天数）。零聚合规则、无 θ/ε 硬门；θ=0.85 与 β-二项/Wilson
（裁决 12）保留为**展示层**（KF-20 透明度：保守分 + 区间 + 证据摘要）。

## 3b. 曾摆出的选项（历史记录，均未采用）

```python
# (1) 小 n 表
import math
z=1.959963984540054
def wilson(s,n):
    p=s/n; d=1+z*z/n
    c=(p+z*z/(2*n))/d
    h=(z/d)*math.sqrt(p*(1-p)/n+z*z/(4*n*n))
    return (max(0.,c-h),min(1.,c+h))
def need(eps,f):
    for n in range(max(1,f),500):
        s=n-f; lo,hi=wilson(s,n)
        if hi-lo<=eps and (s+0.5)/(n+1)>=0.85: return n,s
for eps in (.15,.20,.25,.35):
    print(eps,[need(eps,f) for f in (0,1,2)])
```

```python
# (2) 现状 EMA+Wald 成本
import math
def cost(fail_every=0):
    p,M=0.5,0.0
    for i in range(1,200):
        p=(p-p*0.42) if (fail_every and i%fail_every==0) else (p+(1-p)*0.32)
        M+=1.0; lb=p-1.2*math.sqrt(p*(1-p)/(M+1))
        if lb>=0.85 and M>=2: return i,p,lb
print(cost(), cost(4))
```

```python
import math
w=[0.212,1.2931,2.3065,8.2956,6.4133,0.8334,3.0194,0.001,1.8722,0.1666,0.796,1.4835,
```

```python
# (4) E 的知识点记忆卡成本：n 道绑定题同日初错、各自 r*=0.9 全 GOOD；记忆卡吃作答流
import math
w=[0.212,1.2931,2.3065,8.2956,6.4133,0.8334,3.0194,0.001,1.8722,0.1666,0.796,1.4835,
   0.0614,0.2629,1.6483,0.6014,1.0,0.5425,0.0912,0.0658,0.1542]
dec=-w[20]; F=0.9**(1/dec)-1
ret=lambda t,S:(1+F*t/S)**dec
ivl=lambda S,r=0.9: max(1,round((S/F)*(r**(1/dec)-1)))
D0=lambda g: w[4]-math.exp(w[5]*(g-1))+1
def nD(D,g):
    tgt=D0(4); dl=-(w[6]*(g-3)); return min(10,max(1,w[7]*tgt+(1-w[7])*(D+(10-D)*dl/9)))
def nS(D,S,R): return min(36500,max(.001,S*(1+math.exp(w[8])*(11-D)*S**(-w[9])*(math.exp((1-R)*w[10])-1))))
def sS(S,g=3): return min(36500,max(.001,S*max(1.0,math.exp(w[17]*(g-3+w[18]))*S**(-w[19]))))
def sim(n):
    probs=[{'S':w[0],'D':min(10,D0(1)),'last':0,'due':1} for _ in range(n)]
    kc={'S':w[0],'D':min(10,D0(1)),'last':0}
    att=0
    for day in range(1,400):
        for p in probs:
            if p['due']==day:
                R=ret(day-p['last'],p['S']); p['D']=nD(p['D'],3); p['S']=nS(p['D'],p['S'],R)
                p['last']=day; p['due']=day+ivl(p['S']); att+=1
                t=day-kc['last']
                if t==0: kc['S']=sS(kc['S'])
                else:
                    Rk=ret(t,kc['S']); kc['D']=nD(kc['D'],3); kc['S']=nS(kc['D'],kc['S'],Rk)
                kc['last']=day
                if kc['S']>=21: return day, att, round(kc['S'],1)
for n in (1,2,3,5): print(n, sim(n))
```
