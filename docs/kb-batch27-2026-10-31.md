## 5. R3/R4：截断安全（交付门 F7）

### 5.1 实现

`core/data/src/main/kotlin/com/tingyun/smartmistakebook/core/data/study/RoomTutorToolRunner.kt`：

- `safeTruncateMarkdown(text, limit)`（`:91`）：
  1. 切口落在 `$$...$$` / `$...$` / `\(...\)` / `\[...\]` 内部 → 退到公式起点，整段公式下沉；公式从第 0 字开始则回退 `take(limit)`。
  2. 否则退到 `limit` 之前、且不在公式内部的最后一个句号/分号，保留完整句子。
  3. 两者都没有安全点 → 原样 `take(limit)`（与旧行为一致）。
- 调用点：boundary `safeTruncateMarkdown(it, 80)`（`:447`）；材料摘要 `safeTruncateMarkdown(it, KNOWLEDGE_READ_MATERIAL_DIGEST_CHARS)`（`:449`）。
- 结果形态与预算不变：最多 5 行、boundary ≤80 字、材料摘要 ≤60 字、整条结果 ≤2,000 字符（`TutorToolOutcome.MAX_TOOL_RESULT_CHARS`）。

- 11 个用例覆盖：`$...$`、`$$...$$`、`\(...\)` 三种公式回退；公式在第 0 字回退旧 take；句号/分号句界；公式内分号不误判；无公式无句界回退；boundary 集成（半句不下沉 / 完整范围句保留）；材料摘要集成（公式回退 + ≤60 字 + 2k 字符预算）。
