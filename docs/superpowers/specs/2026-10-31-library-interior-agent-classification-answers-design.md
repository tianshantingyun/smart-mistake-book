# 错题本内页 A 方案：智能体修改、全库分类与详细答案设计

日期：2026-10-31。状态：用户已确认设计方向、答案补全方式、跨学科关联边界及两份正式文档路径；生产功能未实施。

## 已确认的决定

- 使用 A「阅读优先」：题面、完整原图、笔记和分类依次呈现。保留青绿主色与现有软件的视觉语言。
- 编辑页需要智能体入口，支持文字、公式和题图修改，图像修改不能停留在替换文字说明。
- 分类应覆盖整个知识库，支持词语或整句输入、关键词模块以及直接选择知识条目。
- 用户已确认允许关联其他学科的知识点，题目自身的学科保持不变。
- 导出可另存详细答案。用户已确认优先复用已有有效解答，缺失部分由智能体补全，预览确认后导出。

## 1. 编辑页中的智能体修改

### 界面

在现有编辑页内容顶部增加一条低饱和蓝色的「让智能体修改」入口，次级按钮为「描述修改」。保留手动修改表单，不将用户带到一个与题目脱离的普通聊天页面。

打开后明确显示修改范围：题面文字与公式，或某张已有题图。多图时逐张显示可辨认的名称和完整预览；原始拍照证据与可修改题图分开。允许描述修改要求，不在本批新增画笔、蒙版或自由裁剪编辑器。

路径为：描述修改 → 提交 → 修改建议 → 对比修改前后 → 采用到草稿 → 现有「保存修改」。取消建议不改草稿；采用建议也不立即覆盖书中当前版本。

### 数据与执行

模型只接收本次明确选中的题目版本、草稿内容、目标图身份及允许读取的源图。不接受模型编造的本机路径或远程图片地址作为新题图。

建议返回类型化的编辑操作与产物引用。文字修改沿用现有结构化内容编辑约束；题图替换携带目标 block/figure id、旧资产身份、新 `FigureArtifactRef` 和变更摘要。文字与图形有关联时作为同一建议原子采用，避免文字仍是旧条件、图形已经变更。

实际绘图经统一 `FigureGenerationCoordinator` 执行。承载任务中的模型根据目标、源图保真需求和当前能力选择 JS 绘图或图像模型；不是由「编辑页」「讲解图」等入口名称硬编码决定。源图像素保真编辑必须使用具备相应能力的方法；JS 未装配时不可声称可以执行。失败不能偷偷改换方法、追加付费或覆盖原资产。

任务身份绑定：entry id、基准 revision id、草稿指纹、目标图 id、源图 SHA、规范化修改要求的摘要。相同点击幂等；不同要求不能命中旧净化结果。状态需要持久化，区分排队、执行、建议可用、取消、失败与过期。打开页面、查看原图或预览建议均不触发远程生成。

保存继续使用现有基准版本冲突检查。生成期间题面或本地草稿已改变时，结果只能作为过期建议查看，不能自动覆盖新内容；用户重新基于当前草稿发起修改。原始拍照证据保持只读，新题图进入新版本的结构化引用。

### 失败处理

没有合适模型、源图不可读、服务失败、当前版本已变更时，显示准确原因并保留手动草稿。重试沿用同一逻辑任务的次数与预算控制。修改失败不影响原题和已有有效图。

## 2. 全知识库关键词分类

### 界面

搜索框接受词语或整句话。将知识名称、别名和已发布知识描述中匹配到的有意义词组展示为关键词模块；不把底层检索的二元/三元字串直接当成用户标签。

点击关键词筛选结果；点击知识条目加入现有分类选择。结果按学科和章节分组，每项展示知识点名称、完整目录路径、匹配描述和少量关键词。空查询也能按目录直接选择。已选项明确标注，防止重复添加。

例如输入「我想查找二次函数的最小值」，出现「二次函数」「最小值」等模块；输入「数量积」，数学的「向量的数量积」和物理的「恒力做功」可以同时出现。名字相同而目录不同的节点不能合并。

### 检索实现边界

增加面向用户目录的分页读口，查询范围为全学科中已发布、仍有效、允许展示的知识内容，包含名称、别名、知识描述及可展示教学段落。原始外部材料和未审核模型候选不直接冒充已确认知识条目。

第一版用数据库读侧的完整内容查询与稳定游标分页保证覆盖率，不把首批 256 个节点载入内存后过滤，也不以讲题召回的 top-k 或有损特征索引限定集合。已有索引可用于排序加速；若缺少某些别名/段落，必须由完整字段匹配补齐。搜索语句参数化，通配符按普通输入转义。

默认每页 32 项，输入防抖 250 ms，后台查询并取消过期查询，页游标绑定查询条件与知识库版本。关键词提取在本机完成，不逐键调用模型。全库更新、节点合并、退役或还原后须失效旧页与缓存。

### 跨学科绑定

扩展选择命令，以知识节点稳定 id 和 taxonomy version 为准，在写入时重新校验节点仍有效。显示名、整句话和关键词字符串均不是绑定身份。

用户明确选择的跨学科绑定可以写入当前题目版本；保留节点真实学科及目录路径，题目的主学科不变。不能通过把知识点名称伪装成当前学科的自定义标签来实现。

本次用户操作不自动扩大讲题工具的数据披露范围，也不把物理知识证据计入数学节点。自动分类原有的学科边界保持原有约定；跨学科新增只由明确的用户选择产生。现有纠正分类的确认与版本冲突检查继续生效。

## 3. 详细答案独立导出

### 界面

现有格式选择中增加默认不勾选的「另存一份详细答案」。未勾选时走现有题目导出；勾选后主操作为「准备答案并预览」。

准备完成后展示各题的最终答案与完整解题步骤，公式正确排版，有已有讲解图时按能力展示；逐题区分「复用已有解答」「智能体补全」「仍缺失或待核对」。用户预览确认后分别导出题目文件和详细答案文件，题目文件不混入答案。

### 答案来源与有效性

先冻结导出对象的题序、精确题目版本和导出编辑副本指纹。有效旧解答必须针对这份题面，且包含可用于交付的最终答案与解题步骤；旧版讲解、未完成对话、学生选择的选项或学习笔记不自动当成正确详解。

若导出副本修改了题目条件，原题解答即使有效也不能直接复用。对变化后的副本重新准备答案，或明确指出无法复用。缺失的解答经现有模型任务基础设施补全；打开导出面板、勾选选项本身不触发调用，点击准备才执行。

将解答落为结构化文档：最终答案、面向用户的解题步骤、公式、所用题图/讲解图引用、来源与核对状态、题面/副本指纹、模型任务身份。不将聊天记录直接拼接成答案，也不索取或导出模型内部隐式思维链。

可以使用确定性检查和已配置核对能力，但模型生成、用户预览和正确性验证必须使用不同状态。没有独立验证依据就标为待核对；用户预览确认只记录已查看，不升级为「已验证正确」，也不写学习掌握证据。

新增答案配图仍走统一绘图协调器和相同 JS / 图像模型判定规则。不能为了美化每道题无条件生成插图。

### 渲染、后台任务与交付

为完整文字详解增加独立渲染输入，支持答案标题、题号、步骤文本、公式、分页和关联图。不能仅设置现有 `includeAnswer` / `includeSolution` 就声称已经支持详细答案。

题目与答案共享同一导出组、冻结题序和题面指纹，但各自产物身份、状态、文件名、校验值及保存动作独立。沿用后台任务、文件验证、保存和分享机制，答案失败不把已成功的题目文件改成失败。允许先保存题目，再仅重试缺失答案，重复操作不重复生成已成功解答。

单题和批量共用这套逻辑。批量答案题号与题目卷完全对应。重排或删除使整份答案卷与预览确认失效，但未改写题面的逐题解答仍可复用；改写条件或题图使对应逐题解答失效。历史版本导出使用历史题面及其对应解答，不读取当前版本冒充。

PDF 与 Word 共享结构化答案数据。Word 仍需如实显示当前图形以文字说明呈现的限制，不把这一批暗中扩为整个 Word 图形引擎重写。完整文字步骤与公式不能因原有「解析区暂不可用」逻辑被静默跳过。

导出缓存身份包含产物角色、格式、题目/副本指纹、答案内容指纹和版式。答案文件损坏、丢失或生成中断时不能显示可保存的成功状态。恢复和备份只恢复可校验的持久事实，设备缓存路径不作为可靠的答案内容。

## 分批实施与验收

1. 先明确领域命令、可用能力、版本身份及三条链的状态，补齐错误与冲突契约。
2. 落实全库分页查询与按 id 的跨学科选择，使用超过 256 个节点和同名跨科节点验收。
3. 接通智能体编辑任务、统一绘图与草稿采用，再接编辑页入口；不展示无后端的可用按钮。
4. 接通详细答案快照、复用判定、补全任务及 PDF/Word 渲染，再接预览与独立交付。
5. 以已确认 A 布局整合原生详情、编辑、分类与导出界面，保留原图完整比例、已有交互标签和可访问性。
6. 对受影响模块运行相关单元、集成、构建与原生交互检查，覆盖取消、重复点击、离线、模型不可用、晚到结果、题面修改、分页、部分成功和文件丢失。真实模型链未运行的部分须如实记录。

这些是实施边界，不是已经完成的功能清单。原型只验证交互表达；不会调用真实智能体、查询用户知识库或生成导出文件。
