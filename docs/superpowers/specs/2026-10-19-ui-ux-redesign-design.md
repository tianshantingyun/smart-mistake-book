## 1. 目标与边界

学生打开应用就知道当前能做什么；阅读题目优先于操作面板，完成一个任务不必绕进聊天；失误、中断和模型不可用时仍能找到下一步。维持纸色、墨色、玉绿色的识别基础，收敛强调层级、减少边框和大块按钮，形成清楚、安静的学习界面。

沿用Android/Compose与现有core:ui，不引入React、WebView页面系统或另一套设计框架。不增加手写演算板、社交、账号、商店、强制新手教程、每日虚假打卡或第二个首页。当前只设计既有浅色主题的改进；深色主题若后续交付须独立验全色对，不能本轮声称支持。

五个**功能分区**仍是智能体、复习、错题本、学习档案、设置；不等于五个底栏格。保留当前四个底部目的地“复习 / 智能体 / 错题本 / 我的”，后两功能分区在“我的”清晰分组。当前源码与已安装包支持这一映射。本轮不改变会话隔离、三键证据、3D启用门、六派发上限、四科知识画像边界或统一生图决策。

## 2. 导航与动作规则

| 场景 | 入口与返回 | 约束 |
|---|---|---|
| 切根页 | 四个底部入口；记住各列表位置/筛选 | 智能体显式重新进入按原裁定开新会话；“历史继续”、配置返回及恢复原会话不误开新会话。按明确导航原因区分 |
| 题目详情/编辑 | 从来源栈打开；返回恢复原筛选、位置和选择 | 不返回默认首页；题目历史版本只读，不暗中切到新版提交 |
| 复习中的求助 | 当前卡片内“提示/问一问”打开该复习会话覆盖层 | 返回恢复答案、计时与曝光状态，不跳入无上下文的智能体新会话 |
| 详情中的讲题 | “问这道题”到智能体，以题为本轮附件 | 不自动存题或记为作答；智能体正常模式与复习引导模式分别保持 |
| 录入 | 单一录入流，保留LIBRARY/TUTOR来源语义 | 待处理题仍在录入流，不能塞进已保存题列表；可在其他页提供“继续录入”的导航摘要 |
| 导出/后台任务 | 发起后可离开；成果永久入口与通知汇入同一详情 | 悬浮任务入口只在有任务/待确认时出现；不另造“最近所有动作”流水账 |
| 设置返回 | 返回原问题、草稿、格式选择或失败任务 | 保存配置不自动测试或发送；进程重建后的外发由明确“继续”恢复 |

同一可见工作区只有一个填充色主动作；“主动作”由当前任务阶段决定，其他动作使用次级按钮/文字。三键评分是同一决策组，不能通过一个绿色超大按钮诱导某个评分。两复习入口都可选，不以推荐顺序锁死流程。

短参数选择用底部面板；长题目编辑、文档编辑、原图比较用全页。键盘和大字使面板容纳不下时转全高布局，不增加第二层套娃面板。一次最多一个模态层。返回优先收键盘、退出当前模态，再退页面；未保存内容只在确实会丢失时提示，已可靠保存的草稿不重复打断。

## 3. 视觉基准与适配

这些是改版起点，须用真实内容验收，不是所有控件强制固定尺寸。

| 项目 | 目标 |
|---|---|
| 背景/文字/主色 | 2026-10-23按用户源码照搬裁定：画布`#FCFCFB`、正文`#151515`、次要文字`#525252`、白色浮层，保留Jade `#23704A`。正常文字不用InkMuted承担；真实对比度由当前色对测试核验 |
| 状态色 | 成功、警告、错误分别有文字/图标/底色令牌；不把橙色一律当危险。普通错误文字不能沿用低对比ErrorWarm；图表的科学标记色不依赖红绿判断 |
| 字号/行距 | 按上游角色：页题20/26sp、会话顶栏14/20sp、分节16/22sp、输入15/21sp、说明14/22sp、紧凑控制12/18sp；既有题卡18/15/14sp及数学讲解正文保持阅读要求。系统字号偏好生效 |
| 间距 | 4/8/12/16/24/32dp等级；手机横向16dp，宽窗口24dp；同组8–12，组间24，避免每行都加大留白 |
| 容器 | 沿上游源码区分：输入外壳20dp、用户气泡18dp、普通卡片12dp；正文不包卡片。输入为整行书写区加下方工具栏，助手身份位于正文上方，不用侧边头像挤窄正文 |
| 控件 | 触区至少48dp，主按钮常态最小52dp且可随文字增长；图标通常24dp。不压小触区来解决首屏拥挤 |
| 导航/页头 | 使用统一页头和Material3导航测量；消除重复固定高度/重复inset。标题、内容和底部动作栏各只承担自己的空间 |
| 动效 | 遵守系统减少动画偏好。会话仅在用户位于尾部或明确发送/点击回到最新时按既有规则跟随；向上阅读不抢回，新会话从欢迎开头阅读。禁止装饰性自动滚动和假进度；发送按压采用上游0.95缩放与150ms过渡 |

可访问性验收以实际合成后的颜色和背景为准，普通文字至少4.5:1；图标、控件状态按适用标准检查，禁用例外不用于正文说明。填充按钮的文字色、选中Chip及图片内说明需另验，不是全局改一个颜色就完成。

按可用窗口适配：小于600dp单列；600–839dp保留单列阅读，必要时用导航侧栏；840dp以上错题列表/详情、原图/编辑可采用双栏，各栏至少320dp并避开折叠铰链。阅读正文沿用约600dp最大宽度；工具侧栏独立，不把长文拉满平板。窗口高度不足、键盘打开或大字时优先保证单任务可操作，不强保双栏。

验证320/360/412dp窄屏及600/840dp窗口；fontScale 1.0/1.3/2.0、横屏、分屏、键盘、手势/三键导航。2.0时允许页面变长；不缩字、不截掉题目或操作。图形可横向滚动/放大，但不能让整页跟着横向溢出。

## 4. 页面结构与使用流程

### 4.1 复习：进入任务，空态给下一步

```text
复习                     队列
[错题] [知识点]          本次 3/12
──────────────────────────
当前题面 / 公式 / 图
作答区域（按题型提供，原生控件）
提示 / 问一问           暂时跳过
──────────────────────────
按这次独立作答自评
[做错了] [有点卡] [做对了]
```

有已开启会话则续当前卡；新进入时按队列提供待开始题面/开始动作，不能把浏览记作作答。首页不再先放问候、大统计和重复“开始今日复习”中转。知识点入口的可用数取真实队列；未加载不显示0，未启用不提供假入口。

三键明确对应Again / Hard / Good，记录SELF_REPORTED。学生可在纸上作答，不强制手写板或转写输入；存在原生作答字段时与自评在一次稳定提交中持久化。三键是自评，不宣称机器已判对；提交成功后才展示答案与结果、备注折叠项和“下一题”。正常判定后展开不算提前曝光；主动提前看答案保留既有曝光语义。客观小测采用其独立提交/判分流程，不再追加同次三键造成双记分。没有可信答案时如实说明自评属性，允许跳过。

结果区保留“撤销本次评分/评分有误”入口，不能只靠几秒Toast；撤销后重评不抹掉已经发生的曝光。答案疑问入口中性显示，未揭示时不把正确选项写进按钮或读屏标签。所有新真实学习写入仍依PRD-02/03/05与3D门启用。

无题：“还没有可复习的题”+“录入第一道题”；有题无到期：“今天没有到期题”+查看错题本；当天完成展示真实完成数与“查看本次结果”。没有记录不画0分雷达，不用灰色不可点的大按钮充当空态。

### 4.2 错题本：列表优先、筛选按需

```text
错题本                     PDF文件 ＋录入
[搜索题目、板块或知识点              ]
12道 · 最近更新           [筛选 2] [导出]
物理 ×    力学 ×    近30天 ×
┌────────────────────────┐
已保存题图直接外显，保持比例
多页题图按来源阅读顺序排列
题目标题                         收藏
最多两行题干摘要
物理 › 力学                  掌握状态标签
└────────────────────────┘
下一条题目……
```

2026-10-21按用户可读性反馈收紧文字基准：题名18sp/半粗、摘要15sp/中等、科目与状态14sp，正常正文和标签使用既有Ink近黑字色，不把信息层级做成浅灰小字。层级主要由字号、字重和间距表达；浅色底与轻边框保留。题图占满卡片可用宽度，保持完整比例，不通过重绘或滤镜改变原图内容。对比度计算针对实际字色/底色组合，不能据此宣称所有图片和整个应用通过无障碍验收。

完整筛选面板默认收起，展开消费已有科目/板块/掌握程度/收藏/录入时间能力及两种排序；当前排序随数量显示，长选项行可横向滚动。知识点仍可搜索，不重新增加已裁定删除的知识点筛选层。选中条件在面板收起后仍可见、可单项撤销，沿原科目/板块级联规则执行。列表标题单源`revision.title`；长题标题两行、正文摘要最多两行，完整内容在详情，公式摘要需保持语义不截半个公式。

2026-10-21按用户要求调整为题图外显，后续美化批细化为“题图在上、信息在下”的浅色题卡：题图优先阅读，标题与独立收藏放在下方，摘要次之，科目路径与掌握状态标签分开，避免长路径挤掉状态。保留纸色玉绿主题，沿已有排版与形状令牌，弱化重复边框；搜索框平时用浅色面区分，聚焦才强调边界。去掉大号学科圆标和重复进入箭头；整张题卡沿原入口打开详情，收藏仍只修改收藏。只读取已保存的本地图片，不自动调用JS或生图模型；图片宽度随卡片自适应，高度按比例有界，长页不拉伸裁切，完整阅读沿详情入口。现代题面按证据中的来源顺序排列，多页逐张展示；手动无图题保留文字，损坏或缺失图给局部可读提示，不阻塞列表。

“导出成果”永久入口放在页头PDF图标，常规宽度加“文件”文字区分查看成果与发起导出，窄屏/大字收为图标并保留完整读屏标签，空库也可进入；工具栏紧凑“导出”沿现有**当前筛选结果**合同发起，读屏标签包含完整数量，收集全量匹配ID并沿原上限处理，不把当前加载页冒充全部。本轮不引入逐题选择模式，也不改变后台导出、通知退化入口和返回目标。归档管理沿现有“已移出的题”折叠区收紧，保留恢复入口，不增加真删除。

360×800dp、fontScale1.0、默认筛选时，控制区目标不超过可用内容顶部240dp，普通高度题图首屏可直接阅读一张完整题卡；超长页/多页不强制整卡塞进首屏。输入框使用最小高度，随大字号增高，按钮保留48dp触区；大字不强制上述密度目标。无搜索结果给清除条件；真正空库给录入，不把两种空态混为一谈。2026-10-21实现与定向证据沿计划第9节登记，分页失败/恢复回执等未完成项不据此关闭。

### 4.3 录入：新任务与继续任务都能找到

```text
‹ 录入                       待处理 2
存入错题本 · 原图会保留        详情⌄
[拍照] [相册] [整卷/PDF] [手动建题]
（窄屏换两行，特大字换短列表）
──────────────────────────
待处理题目
缩略图  题目摘要/来源 · 时间     继续 ›
        已保留，等待补充             ⋮
```

保留单一录入入口，进来才选方式；在LIBRARY来源开放手动建题，不把尚需照片的讲题来源伪装可用。四方式不用四个等重的大块主按钮；当前选中方式或实际下一步才突出。顶部待处理摘要滚动到同页列表，空待处理不占整屏。

处理状态只说业务：已保留原图、正在整理、等待补充、已存入、暂未完成；内部task/ledger/schema不进入正文。进度有真实总页数才显示“完成3/8页”；无法估算时用阶段文字。多题保存逐题有回执，失败只重试对应任务，不要求重新拍。

草稿卡用缩略图/来源/时间/页码辨识，不重复只有“新拍题目”；继续为主，丢弃进更多并说明丢掉什么。预览/转写/图片原件可切换，修订是主动入口，不增加强制OCR逐字段确认。自动切分未过门的限制保持。

### 4.4 题目详情、修改原题与答案纠错

```text
‹ 题目详情                       ⋮
标题（完整显示）        科目 · 板块
题面、公式、图；原图可查看
[解析（按当前上下文控制揭示）] [备注]
──────────────────────────
[问这道题]     修改题面     导出
```

普通浏览先给完整题面；版本、关联题、来源与技术追溯折叠到详情信息，历史版本显式“旧版，只读”并有回当前版入口。当前详情的主动作先保留“问这道题”；“再练”须真实接入PRD-05后才提供，不能先造按钮。复习来源的答案显隐沿会话状态，不能打开详情绕过曝光记录。

“修改这道题”是全页编辑：题干/选项/答案/图/备注按实际可编辑范围分组，原图为参考，公式有可见预览。底部“保存修改”，返回保留草稿；无变化不制造revision，保存失败保留输入。版本冲突提供“查看最新题面”和保留本地修改供比较，不自动覆盖或把CAS失败当成功。

“答案有问题”打开目标明确的纠错面板：当前题/答案版本、问题类型、说明、可选修正。提交回执区分“问题已记录”“已暂停该答案计分”“正在更新学习记录”“更新完成”；只有目标checkpoint追平才说完成。无法定位的旧记录说明影响未确定，不显示假“已修好全部”。这与修改试卷副本分离。

### 4.5 智能体：对话优先、能力入口精简

```text
智能体             新对话  历史  ⋮
直接回答⌄                  当前附件 1
──────────────────────────
新会话：一句说明
[拍题讲解] [从错题本选题]
试一句：明确标记“点击发送”的短示例
更多能力⌄
（有消息后让位给会话正文）
──────────────────────────
需要配置时的一行说明 + 配置入口
[＋] 输入消息……                 发送
```

模式切换收敛为短控件，展开后解释正常/引导差异；不在每屏重复“它能做什么”的长目录。示例继续遵循已裁定S5点击即发送，标签和提示要诚实，缺能力时不可暗发。拍题、选题等原生导航与发送示例视觉分开。

标题与底栏统一“智能体”，当前问题是副标题/附件；历史回到原会话。模型配置阻断贴近输入区，保留输入能力与草稿；提供明确配置入口，禁用发送有理由。401、限流、缺图片能力分别说明，不统一写“还不能处理对话”。设置返回不丢草稿，不自动续发。

流式内容沿既有块级/公式渲染；用户上滑后停止自动追底，出现“有新内容”回底按钮。只在用户跟随最新消息时追底。生成/停止状态占同一按钮位置；停止不删已显示内容，迟到结果以当前回合身份校验。工具过程默认一行状态，可展开用户可见摘要，不展示内部隐藏推理或原始执行代码。

### 4.6 讲解图、公式和原生交互

题目/讲解/详情/导出预览共享内容块：段落、标题、列表、公式、表格、图、原生表单。保留模型自由编排，宿主只统一留白、字号和动作边界，不按题型写六套页面。JS/IMAGE_MODEL同一判定，图卡不让学生先选后端；在原权限/预算内修复换法不新增逐图确认。

- 比例图有数值/图例，不能仅凭颜色；F-x图的阴影、坐标和单位与题意一致。
- 纯流程示意可自由绘图；可点击的流程步骤与单选/输入/提交采用原生控件，不能烘焙成图片。
- 受力箭头必须表示实际方向；阶段图有阶段标签；不靠“仅示意”掩盖语义错误。
- 数学公式完整后再排版，流式未闭合片段暂存到有界缓冲；永久失败给可读文字与“查看原式”，不让裸TeX伪装成功。长公式用明确横向滚动/放大，不把字号缩到不可读。
- 图内标签遵守通用布局/可访问性契约；原始位图不能重排文字时给放大与等价文本，不裁掉标签。表格和流程卡窄屏优先纵向化。

图卡状态：生成中给稳定占位和停止；有旧图时更新失败保留旧图并标明；成功图支持放大、图注、文字摘要。保存/历史/导出/滑块回放不重新生图；“重新生成”是明确动作并沿宿主策略执行。JS不可用时不展示假交互；未知版本恢复用已验证静态快照并说明互动暂不可用。

原生表单显示问题、选项整行可点、理由标签和提交按钮；必填/可选明确，不能只用placeholder。提交中去重，失败保留答案；反馈不是掌握写入成功的同义词。交互图控件位置在图下，提供滑块数值、步进/重置；拖动不劫持整页滚动，辅助功能有非拖动操作。

### 4.7 导出、试卷编辑与成果

```text
‹ 导出文件                 已选 12 题
格式：   (PDF)  (Word/DOCX)
布局：   A4练习卷⌄          预览
内容：   题目✓  留白✓  答案附件□
题目列表：调序 / 移除（仅本次导出）
──────────────────────────
保存题目本体不受本次排版修改影响
[生成文件]
```

短格式选择可用面板，题目很多或编辑文字时进入全页工作区；复用已有编辑草稿和双渲染器。默认题目区不带答案；答案附件独立说明，预览标明仅预览/实际版本。改条件后过期图明确提示与修复，不自动重画每一处文字。

提交后显示后台状态和“查看文件”；成果分生成中/可交付/失败/源内容变化，逐条保留重试与原文件。空成果页给“选择题目”。“已生成”不等于“已保存到选择的位置”，调用系统分享不等于分享成功；保存取消回到成果页，不重复生成。文件名、格式、题数、更新时间可见，路径和日志放详情。

### 4.8 我的、设置、备份恢复

“我的”分学习档案、学习偏好、模型与数据三个视觉组；真实有证据才显示本周/薄弱项摘要。学习档案可进入全览、复习历史与薄弱点复习，不直接编辑数值，也不新增被排除的证据链深钻。四科支持范围与未知/无证据分开表达。

设置文案采用“模型连接”“复习安排”“提醒”“备份与恢复”“存储管理”；必要的Provider/Base URL/API Key留在配置表单，FSRS和内部开关进高级设置，不在根页解释实现。保存配置与主动连接测试分开。

备份页面给最近一次可恢复备份的真实时间、内容范围、存储位置、创建/校验结果；不把文件存在当已验证。恢复依次呈现选包→预检摘要→说明会替换的数据→执行→结果；这沿既有恢复确认，不给普通生图增加确认。选择恢复内容时必要依赖锁定并解释；进度/空间不足/版本不支持/部分设置恢复分别显示。不可取消的交换阶段如实说明，不放无效取消按钮。

## 5. 状态、恢复与反馈矩阵

| 页面/组件 | 加载与空态 | 失败/不可用 | 成功与恢复 |
|---|---|---|---|
| 复习 | 未加载不写0；无题/无到期/完成分开 | 数据加载失败有重试；未启用功能不冒充无题 | 按持久会话恢复，评分成功才推进，撤销可追溯 |
| 错题列表 | 首载简单骨架；刷新保留内容；搜索空态可清除条件 | 分页失败只提示对应区，既有题仍可打开 | 保留筛选/滚动/选择；结果数不把当前页当全量 |
| 录入 | 本地收妥才说已保留；无待处理隐藏多余框 | 补图/限流/任务中断各给实际下一步 | 已入库回执与待处理互斥；返回不重复任务 |
| 编辑/纠错 | 加载冻结版本；字段有标签 | 保存失败保留；冲突保留本地稿；争议与修复中不同 | 等持久回执/checkpoint，不用Toast代替状态 |
| 智能体 | 新会话简洁；历史读取不生成 | 缺配置/401/限流/取消分别处理；重建只读恢复 | 恢复原草稿、附件、模式和锚点；外发需继续 |
| 图与公式 | 有界占位/缓冲，不闪裸TeX | 保留旧图或文字退路，语义未证实不贴正确徽章 | 放大/摘要/静态快照可读，零自动再生成 |
| 原生表单 | 默认未选择，不自动填正确项 | 校验在字段旁；提交失败保留答案 | 双击幂等，题版本变化阻止错题提交 |
| 导出 | 格式/布局与选择可预览；空成果有入口 | 缺必需图显式失败，保留上一文件 | 生成、保存、分享状态分开；取消可回原处 |
| 档案/备份 | 无证据不显示假统计；预检与执行分段 | 部分恢复不当全成功，空间不足不无限重试 | 只显示真实范围，恢复不自动外发 |

错误信息回答“发生什么、内容是否保留、下一步是什么”。短暂提示仅用于轻量反馈；需要处理的失败留在对应对象处。不要全屏错误覆盖仍可阅读的本地内容。页面可见状态由既有业务状态派生，UI不能自行将pending改为success。

## 6. 组件、状态归属与拟定接口

```text
App / existing Scaffold
├─ Root navigation + contextual task indicator
├─ feature Route (existing ViewModel / use cases)
│  ├─ ScreenHeader + PageStateFrame
│  ├─ Feature content (list / card / edit / conversation)
│  │  ├─ QuestionContent / existing rich text + math
│  │  ├─ FigureArtifactCard / native form
│  │  └─ TaskStatusCard / ResultActions
│  └─ ActionFooter or Composer (one owner of keyboard insets)
└─ One modal host (filter / export options / correction)
```

优先复用`Theme`、`Components`、`PageStateFrame`、`TutorMarkdownTokens`、`AiReplyRichMarkdown`、`TutorStreamingReply`、`MathBoxComposeRenderer`、`BoundedLocalImage`、`AttachedImageCard`。抽共享组件基于实际两处消费者，不先建设通用低代码框架。

| 拟定UI接口（实施前映射既有类型） | 必需输入 | 输出事件 | 禁止职责 |
|---|---|---|---|
| ScreenHeader | title、可用actions、返回可用性 | ActionId | 自行判断路由/权限 |
| TaskStatusCard | 对象ID、业务状态、描述、可用操作 | Continue/Cancel/Retry/Details | 自己触发模型或伪造进度 |
| QuestionContent | 冻结题版本、角色、内容块、揭示状态 | OpenSource/Expand/RequestReveal | 展开时自动评分/重新生图 |
| FigureArtifactCard | 已验证图引用、显示状态、摘要、可用能力 | Expand/Retry/Regenerate/ControlEvent | 按用途选后端、访问任意文件 |
| ActionFooter | 一个主动作或互斥决策组、提交状态 | 带稳定目标的动作 | 从按钮本地改成功状态 |
| ExportOptionsSheet | 现有draft快照、候选、格式布局、校验结果 | EditDraft/Submit/Cancel | 修改原题、绕过候选范围 |
| AnswerCorrectionPanel | 题/键版本、可修改字段、回执 | SubmitCorrection/Close | 直接改掌握度或假称纠正完成 |

接口使用不可变UiState与有限事件类型，避免几十个相互矛盾的Boolean；既有PageState继续用于页级状态，局部任务状态独立，不能包一层总Loading就屏蔽整页。以上是设计接口，不是已存在的Kotlin类。

Room/领域持久化负责事实、草稿、任务和回执；ViewModel负责观察与派生页面状态；SavedStateHandle只放有界UI定位、选择及恢复线索。像素、程序源码、长历史不放SavedState；背景化前按现有策略flush持久草稿。展开/放大/筛选不造学习事件；提交带目标版本与稳定操作ID，Route统一调业务命令，core:ui只收参数与回调。

## 7. 验收与实施承接

[UI-00～11计划](../plans/2026-10-19-ui-ux-redesign-plan.md)给出源码归属和验证。每个主要流程交付正常/空/失败/恢复画面及小屏/大字对照；同一题和数据比较改前改后，不通过换短内容掩盖布局问题。

首批产品目标：空库至录入方式选择不超过2次显式点击；错题本搜索无需展开额外页面；详情至原题编辑1次动作；原生导出从选择范围后不超过2次应用内动作即可入队（系统文件选择不计）；输入/错误恢复不要求重新构造原任务。它们是待验证目标，不是已测结果；合法版本冲突、必要数据确认及首次系统授权单独记录，不为了少点击绕过业务门。

UI美感以信息层级、对齐、密度、文字可读性、视觉节奏和控件一致性的前后图评审；可用性以任务完成和无错误副作用判定。颜色、页面截图漂亮、Compose Preview通过三者都不能替代数据/恢复/模型质量验收。

## 8. 2026-10-20 现有操作的具体呈现修订

[UF-01～12审查](../../research/2026-10-20-ui-usability-friction-audit.md)与[UI计划第6节](../plans/2026-10-19-ui-ux-redesign-plan.md)把前文原则落实到现有控件。下述均为待实现结构，不是改后截图；沿原数据/命令/权限，不增加业务功能。

### 8.1 存储页按影响范围分组

```text
‹ 备份与本机存储                 （固定页头）
应用数据库  xxx MB
包含实际的本机数据，不等于学生作答量
题图 xxx MB        可清理 xxx MB

备份与恢复
[创建完整备份]   校验文件 / 从备份恢复
当前操作及结果（与所选动作相邻）

空间维护
清理不再被题目引用的图片

危险操作
删除全部本机数据（沿原确认）
```

UF-01/02只调整命名与动作层级，全部动作仍可达；没有分项统计就只显示真实总量。危险动作与常规清理分开，但不引入新的确认层或清理规则。

### 8.2 配置和考试输入不让学生猜状态或心算

UF-03在字段旁呈现现有事实：未配置、已保存、待保存；空白密钥不得暗示“没有保存”，也不显示密钥原值。保存/测试置灰时旁边给当前原因，成功/失败就地展示，不能把保存成功当能力已验证。保持原保存合同需要密钥时明确说明，不悄悄增加密钥复用模式。专业校准信息折叠在同页，不挤在首次连接任务之前。

UF-04用日期选择/输入表达现有考试日，旁边可显示换算天数，只有一个日期事实源。使用平台或当前依赖可用的控件，不强制升级组件库；取消不改值，确认选择只回填字段，仍由原添加考试动作提交。日期转换按原examEpochDay语义处理，避免把UTC毫秒直接误作另一时区日期。

### 8.3 导出参数、编辑与交付

```text
栏数       [单栏] [双栏]
字号       [小] [标准] [大]
边距       [－]  当前值  [＋]
图形大小   [－]  当前值  [＋]
其余原有参数（按可用空间换行）
```

UF-05保持原参数和值域；短组拆行，长标签换行，不把整个参数面板做成难以发现的横向长条。答案有效状态沿UL-05同源，不能因为改布局又分裂。

UF-06沿已有数学渲染在公式输入旁给预览；不完整输入保留原式并说明无法预览。现有校验失败定位当前题号/字段，用户仍在原稿中修正；不得新加必填规则或替用户自动修文。长编辑继续前文全页布局，保持提交可达和键盘空间。

UF-07将交付反馈绑定本次实际文件，放在对应行附近并可被读屏感知，不强行滚动、不冒报分享成功。UF-11在题目旁使用“从本卷移除/加回”，退出处说明当前回调是否丢弃本卷修改；不把返回改成隐式保存，也不加新确认。原题和文档副本身份保持分离。

### 8.4 找题、浏览档案与取消

UF-08的清空动作只更新既有query，完整候选与顺序不变；长标题/标签按空间合理换行，不能引入新的候选推荐。UF-09保留科目/主题顺序，摘要可见、明细原地展开/收起，保留本次展开与滚动；不截断数据、不新加筛选或深钻，不把浏览当作学习证据。

UF-10把批量照片空回调视为取消，保留原界面和任务；一张仍遵守批量入口已有规则，多张沿原管线，不新增自动转换或导航。

### 8.5 长页页头与原返回规则

UF-12对受影响长二级页采用“现有页头 + 独立滚动正文”的结构，优先配置、导出成果、编辑页。固定位置不改变返回目的地或保存中限制；系统返回与页头返回共用原规则，inset只消费一次。不要把通用RootPageColumn的全部内容固定，也不增加导航栈或另起首页。

## 9. 编辑过程、拆分对象和图片结果的一致性（2026-10-20）

承接[UF-13～19](../../research/2026-10-20-ui-flow-followup-audit.md)及[计划第7节](../plans/2026-10-19-ui-ux-redesign-plan.md)。只修现有交互，不加业务流程。

### 9.1 输入允许尚未写完，提交沿用原校验

UF-13的文本框显示现有编辑状态里的原始输入，不能每次按键都强制变成合法成品。全选删空、中文组合输入、公式未闭合均保留，按draftId/basis/blockId/choiceId隔离。合法候选和预览从输入派生，当前输入不合法时显示原校验问题，提交不能取旧合法值冒报成功。原草稿/返回保护继续，既有持久化不得丢失；不新增自动保存、“应用”按钮或领域校验豁免。

### 9.2 拆分复核页始终回答“哪份任务、到了哪步、点下去做什么”

```text
‹ 原返回       当前任务（沿已有来源摘要识别）
状态：正在准备 / 可以继续 / 已完成（按真实状态）
总计5题 · 已录入3题 · 已选待提交2题
原有来源预览和题目选择行
原命令的在途/失败提示（就地）
[继续录入（2题待提交）]   仍进入逐题确认
```

示例计数只解释层级，实际取台账，不能把total-saved直接算成待提交。UF-14带jobId就只读此任务，不因它退出活跃集换另一份；无目标最近任务入口保持原语义。加载未完成不叫空结果，找不到/已完成只解释该对象并给原返回，不添加任务选择页。

UF-15准备状态不说切分完成，勾选按原仓库的READY条件启用；续做/收尾各自依据真实草稿和原收尾条件，不一概改写仓库允许的状态转换，拒绝/失败可见。UF-16已录入与待提交分开，主按钮表达逐题续做，无行打开能力就不用右箭头，不新增跳转。UF-17有选中PENDING但无草稿属于当前不能继续，按原题号次序处理，保留任务沿原读取/恢复处理，不能跳过缺草稿题或靠complete把问题藏起来；原收尾条件满足才收尾，不伪造SAVED。

### 9.3 图片身份、生成结果与本地显示结果分别准确

UF-18在目标变化当次呈现就隔离旧位图，uri/region和已有asset/revision共同约束消费，加载占位保持当前版面；新图慢/读失败都不能短暂展示上一页题图。不是只等异步producer开始后再置Loading。

UF-19保留图题与已有摘要，展开后本地解码失败要给明确提示，折叠摘要也反映当前显示状态，读屏可知；不能只留“已展开”和空白。生成已就绪与本次文件不可读分开，呈现失败不写回生成台账，不添加无依据的重生入口。

上述消费规则共同覆盖现有原图、转写图、讲解图、导出预览，JS和IMAGE_MODEL仍是统一生图能力的两种方法。查看/切换/展开/恢复零隐式派发；原显式生成动作走同一策略/协调器/预算。不按用途固定方法，不在用户界面展示技术选择流程；尚未上线的消费通道待实现后补验。
