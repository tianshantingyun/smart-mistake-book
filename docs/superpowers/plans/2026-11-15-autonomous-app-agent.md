# 应用内自主 Agent 与 JS 执行闭环实现计划

用户于 2026-11-15 确认应用内操作默认自主执行，并要求同时改进方法选择、连续修正、JS 能力和应用工具覆盖。

## 验收目标

- 已实现且就绪的应用工具可由模型自由组合，意图分类与置信度作为上下文使用。
- 应用动作通过真实处理器执行，完成状态和结果回到模型后续回合，重放使用持久身份。
- JS 与图像方法按真实能力开放，执行错误保留有界的阶段、原因和可修正信息。
- 模型能在同一任务中修正程序、重用产物和继续调用工具，资源耗尽与取消有明确结果。
- 协议广告、解析、权限、处理器和 UI 接线同步验证，升级前数据可继续读取。

## 实施步骤

- [x] 复核工具、动作、JS 引擎与后续请求的真实执行链，列出缺失处理器。
- [x] 调整 core/model 的工具授权与能力快照，以及 core/domain 的默认自主策略，增加对应正反例。
- [x] 补齐 core/data 的 JS 诊断反馈与模型回合消费，验证错误程序修正后成功的完整链路。
- [x] 接通已有保存、打开和导出处理器的自动执行及持久结果，核对编辑与计划处理器的接线边界。
- [x] 扩展实际可执行的工具参数与结果引用，验证跨工具组合和连续调度。
- [x] 统一更新提示词与双协议声明，核对主入口、兼容路径及旧数据。
- [x] 按用户最新指令停止完整回归，完成工具与动作的定向能力检查，记录已通过验证与实际接线缺口。
