### UI-00：锁定真实基线与可审阅画面

- [ ] 记录HEAD、安装包指纹、设备窗口/字体、权限与数据状态；本次API34截图只是观察基线，不能当改后验收。既有样本只用于布局，不把合成题灌入用户库。
- [ ] 为复习、错题本、录入、详情编辑、智能体、图表单、导出、我的/备份制作同内容线框与高保真预览，包含至少正常/空/失败/恢复；每页标主动作、返回目标、数据来源。
- [ ] 每个UX-01～14绑定UI任务/截图/检查结果；评审比较信息层级、找入口成本、可读性，不只评主观配色。不改旧完成记录来冒充改版完成。

退出：设计范围与未达页面可追溯；优先级覆盖P1任务，再进入样式批。

### UI-01：统一视觉令牌与共享结构

位置：`U/Theme.kt`、`U/Components.kt`、`U/TutorMarkdownTokens.kt`、`U/PageStateFrame.kt`。

- [ ] 按设计§3抽字号、间距、圆角、文字/状态色，保留纸色玉绿识别；替换普通文本InkMuted与ErrorWarm低对比用法，并检查真实背景合成。
- [ ] 统一页题/分节/正文层级，取消重复大标题、每段绿竖条、整屏同权重边框；表单错误、选择状态和禁用状态有一致语义。
- [ ] 复用现有页面容器，按实际复用新增`ScreenHeader.kt`、`ActionFooter.kt`、`TaskStatusCard.kt`（拟新增）；单页面专用内容留feature，不建万能组件。

验收：受影响页面同内容前后图；普通字4.5:1、触区48dp；大字布局无硬高度截断；流式/终稿正文令牌一致。关联UX-06/07。

### UI-02：导航、返回、状态与任务入口

位置：`A/SmartMistakeBookRoot.kt`、`A/SmartMistakeBookRoutes.kt`、`U/PageStateFrame.kt`。

- [ ] 固定五功能分区/四底部入口映射；根页名称统一智能体。详情、录入、编辑、导出按来源返回；模态只一层，inset只消费一次。
- [ ] 区分智能体显式新进入、历史继续、设置返回、进程恢复；不能为统一返回逻辑破坏“进入新开”裁定或丢恢复上下文。
- [ ] 把加载/空/失败/不可用/待继续/旧版冲突派生到正确局部，保留可读内容；无题空态提供录入导航。悬浮任务入口可移动且不遮主动作，TalkBack提供非拖动定位方式，不做常驻装饰。

验收：四根页→详情→讲题→返回，配置返回、横竖屏、重建和系统返回均保持正确目标；不意外发送/保存/记分。关联UX-01/11/12。

### UI-03：错题本列表重排

位置：`L/LibraryRoute.kt`、`U/SubjectLabels.kt`。

- [ ] 按设计§4.2把大块动作压入页头、筛选摘要和选择态；完整条件到面板；保留搜索、排序和已选条件可见，未新增知识点筛选层。
- [ ] 统一科目中文标签、单源标题、摘要/缩略图与收藏状态；所有选项仍可访问，不截断长facet列表或用当前页假全量。
- [ ] 已移出题与导出文件保留明确永久入口；选择模式展示范围/数量/上限，导出从明确范围发起，返回保留筛选和位置。

验收：空库、搜索无结果、有图/长标题/未归类、分页失败、收藏失败、多选；360×800/font1.0默认控制区≤240dp、首屏至少1条完整题目。关联UX-02/03/09。

### UI-04：录入与待处理任务重排

位置：`C/CaptureScreen.kt`、`C/components/CaptureScreenComponents.kt`、`C/CaptureCorrectionForm.kt`。

- [ ] 四种方式紧凑分组，来源和隐私一句说明+详情；待处理数量就地可达，缩略图/时间/页码区分任务，不把草稿搬进已保存题列表。
- [ ] 业务状态统一：已保留、整理中、待补充、已存入、未完成；有真实分母才给进度数。继续为主，丢弃进更多；不新增强制校对页。
- [ ] 复用在飞手动题与批量流程；缺配置、相册取消、部分页失败、继续处理、重复题回执均保留原任务和用户输入。

验收：首装空态到方式选择≤2次点击；待处理从同页一步到达；大字可见继续/补充；恢复不重复提交、不自动外发。关联UX-05/12，PRD-06/08。

### UI-05：详情阅读、原题编辑与纠错回执

位置：`L/MistakeDetailRoute.kt`；拟新增`L/EditSavedQuestionScreen.kt`、`L/AnswerCorrectionPanel.kt`，领域契约由PRD-02、PRD-03承担。

- [ ] 题面先行，版本/来源/关联信息后置；解析、备注分区，旧版明确只读；问这道题/修改题面/导出按层级排，不放未接线再练按钮。
- [ ] 编辑有原图参考、公式预览、保存状态和冲突比较；按实际字段显示，不把修改副本与修改原题合并。
- [ ] 纠错面板绑定明确题/键版本，区分受理/争议/重算中/已完成；未揭示答案时不泄正确选项。保存和重算失败保留输入/回执可恢复。

验收：详情1次进入编辑；有变化→保存→重开版本一致；冲突/旧任务晚到/撤销重评不误写；结果状态与PRD checkpoint一致。关联UX-10/12。

### UI-06：复习全屏卡片与三键结果

位置：`R/ReviewRoute.kt`、`R/CapturedReviewSessionScreen.kt`；按PRD-05复用会话事务，不重建调度器。

- [ ] 去掉重复问候/统计中转，建立错题/知识点双入口与队列/当前卡；未加载、未启用、无题、无到期和完成分别显示。
- [ ] 三键文案与Again/Hard/Good逐项对齐，明确自评；一次提交原答案与评分，防双击。正常提交后展开答案，提前揭示仍记曝光。
- [ ] 结果保留学生答案、自评/判定来源、必要评价、折叠依据/备注、撤销与下一题；原生小测判分不再重复落同次自评。
- [ ] 求助用本入口会话覆盖层，返回保持当前作答；统计只读。实际启用前逐条满足3D/PRD门，不因UI可演示就放开写入。

验收：三档、撤销→重评、换题版本、无可信答案、无模型、当日完成；TalkBack顺序与视觉一致，不因打开详情绕过曝光。关联UX-01/12。

### UI-07：智能体空态与会话可读性

位置：`T/TutorRoute.kt`、`T/TutorLobbyRoute.kt`、`T/TutorConversationViewModel.kt`、`U/TutorStreamingReply.kt`、`U/AiReplyRichMarkdown.kt`。

- [ ] 标题统一智能体；模式控件精简；空态一句说明+拍题/选题+少量真实可用示例，更多能力展开；S5“点击发送”语义明确，不偷偷改成填入草稿。
- [ ] 配置/限流/失败贴近当前任务，缩减重复警告；草稿可编辑保存，发送不可用有理由；模式、附件、原题引用可见。
- [ ] 输入区与正文占位统一，IME不遮提交；上滑不强拉底，流式到终稿不丢锚点，停止保留正文。过程摘要默认收起，不新增内部推理披露。

验收：空态、长文、公式、长附件、键盘、停止/恢复、设置往返；旧读覆盖新草稿按PRD-08先复现再修。关联UX-04/07/12。

### UI-08：图、公式、原生表单的统一呈现

位置：`U/StructuredContentRenderer.kt`、`U/MathBoxComposeRenderer.kt`、`U/AttachedImageCard.kt`、`U/BoundedLocalImage.kt`；拟新增`U/QuestionContent.kt`、`U/FigureArtifactCard.kt`，先核是否已有同职责组件。

- [ ] 实施设计§4.6内容块/图卡状态，生成中占位、有旧图更新失败保留、未知版本静态回退；后端选择不成为学生必填项。
- [ ] 比例、坐标、流程、受力、阶段图给标签/摘要/放大；图义与排版分别验，遵守共享提示词，不能按题型硬绑JS或IMAGE_MODEL。
- [ ] 裸TeX/长公式/窄表格/图内中文/原生单选理由提交逐项验；已有原生表单继续可用，新生成式交互按4E.2开放，交互不冒充学习证据。

验收：六张参考图类型、小屏/大字/屏幕阅读器、同产物详情与导出一致；放大/历史/滑块回放0模型派发，显式重新生成才走统一入口。关联UX-13/14，WG-04/06/07/09、PRD-09。

### UI-09：原生导出、编辑与文件交付

位置：`T/TutorExportSheet.kt`、`A/SmartMistakeBookRoot.kt`、`A/SecondaryScreens.kt`；拟新增共享`U/ExportOptionsSheet.kt`，仅收展示参数/事件，不依赖feature:tutor。

- [ ] 复用PRD-04和在飞编辑能力；原生与智能体入口共享格式/布局面板，分别验证合法候选来源；默认不带答案，A4与PDF/DOCX分开命名。
- [ ] 编辑多题进全页；改本次试卷只改副本，失效图给具体处理。重排/排版直接复用已有图，不隐含新模型调用。
- [ ] 统一“导出文件”入口和空态选择题目；生成/保存/分享/打印回执分开，失败留上一文件，重试不重复建卷。

验收：无Key/断网原生单题/多选两格式；从确定范围到入队≤2次应用内动作；系统保存取消、接收应用打开、缺图、版本变化。关联UX-09，PRD-04。

### UI-10：学习档案、设置与恢复界面

位置：`P/ProfileRoute.kt`、`A/SecondaryScreens.kt`及已有设置/备份组件；沿PRD-07，不另造备份引擎。

- [ ] 我的分学习档案/学习偏好/模型与数据，四科边界、无证据和真实薄弱项明确；历史和全览入口可达，普通雷达/周报由真实数据原生呈现。
- [ ] 学生层去FSRS等内部词，技术字段留必要配置/高级页；备份与恢复直达，存储与导出职责不混；连接测试仍由用户主动发起。
- [ ] 备份预检摘要、依赖项锁定解释、空间/版本/部分恢复/不可取消阶段有完整状态，恢复确认沿原合同；不改变归档为真删。

验收：无学习记录/少量/大量四科数据、不可用知识范围、旧包/坏包/部分恢复；恢复后历史图可读且0模型派发。关联UX-08/12。

### UI-11：适配、可访问性与实际使用验收

- [ ] 所有受影响页面补Compose Preview/截图基线：正常/空/失败/恢复；用相同数据、相同窗口做前后对照。极长题干、公式、图注和多行中文不能换短文本来过关。
- [ ] 验320/360/412/600/840dp、fontScale1.0/1.3/2.0、横屏、分屏、IME和系统inset；缩放图有重置/文字替代，双栏窄于约束则退单栏。
- [ ] TalkBack焦点/标题/按钮名/选择状态/错误播报/提交回执可用；触区48dp且不重叠；真实文字色对检查；键盘/辅助设备能操作表单和滑块，不只有拖动。
- [ ] 无模型本地任务、学习提交与纠错、统一生图各走PRD-11链；记录点击数、误入口、丢稿、重复提交/外发。视觉调整不能削弱授权、版本、恢复与质量门。
- [ ] 用目标学生做形成性任务走查，记录人数与设备、找入口困难和改版前后差异；小样本不声称统计显著，也不把主观“好看”当功能验收。

退出：每项分别有布局证据、交互证据、业务回执证据；设备覆盖缺失明确UNVERIFIED。没有本轮实现证据的任务保持未勾选。

## 4. 完成标准

不是“UI已改色”或“页面都画了”就完成。UX-01～14须逐项记录已处理/证据不足/剩余限制；后者带下一步验证，不假关闭。PRD/WG保持原业务验收，UI任务只增加对应页面/状态/视觉门，不把所有基础操作绑定到JS或真实模型上线。
