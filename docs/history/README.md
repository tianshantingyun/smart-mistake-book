# Historical Documents

Files under `docs/` that describe earlier tutor multimodal implementations,
progress, and status pages are historical records. They may describe temporary
implementations that no longer exist and must not be used as implementation
authority. Current contracts live in `docs/current/`.

Drawing-specific update (2026-10-18): historical all-image-model, no-JS, or fixed-scene requirements are superseded by [visual-generation-contract](../current/visual-generation-contract.md). Past test results and defects remain dated evidence, not proof that 4E is implemented.
