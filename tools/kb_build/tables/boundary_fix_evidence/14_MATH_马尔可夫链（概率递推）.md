### 材料 1：[ext-mat-7d94ea3f4b-001] 概率递推问题的构造数列法

**摘要**：

第 n 次操作影响第 n+1 次时，用全概率公式按“上次是否处于该状态”建立递推，再按数列方法求通项。

**正文**：

构造数列型问题通常具备**第 $n$ 次操作的结果会对第 $n+1$ 次的操作产生影响**的特征。例如“甲、乙、丙三人相互传球，求若干次传球后球在甲手里的概率”“第一代开红花或黄花，第 $n$ 代开红花的概率”等，可类比数列的递推公式：前一项的值会对后一项产生影响，故可参考数列递推公式的解题方法。\n\n**建模流程**\n1. 设第 $n$ 次操作后处于所关心状态的“概率”为 $P_n$，并明确 $P_n$ 的含义；\n2. 按第 $n-1$ 次是否处于该状态划分样本空间，用**全概率公式**列出 $P_n$ 与 $P_{n-1}$ 的关系：$P(A_n)=P(A_{n-1})P(A_n\mid A_{n-1})+P(\overline{A_{n-1}})P(A_n\mid \overline{A_{n-1}})$；\n3. 把条件概率的数值代入，即得形如 $P(A_n)=\dfrac{2}{3}P(A_{n-1})+\dfrac{1}{3}\left[1-P(A_{n-1})\right]$ 的递推式；\n4. 再用待定系数法或作差法把它化为等比数列，求出 $P_n$ 的通项。\n\n**要点**：**用全概率公式按“上一次是否处于该状态”划分样本空间**，是建立递推关系的关键一步。

**边界**：

必须先写清 $P_n$ 的定义（第 $n$ 次后处于某状态的概率）与初始值 $P_1$。全概率公式的划分必须不重不漏，且每次操作的条件概率要与该次的状态匹配。最后要用 $0\le P_n\le 1$ 检验通项。

**适用**：

传球、抽球、遗传代数、比赛轮换等前后状态相互影响、求第 n 次概率的问题。

### 材料 2：[ext-mat-7d94ea3f4b-002] 概率递推中构造等比数列

**摘要**：

形如 Pn+1=aPn+b（a≠1）的递推式，配成 {Pn−b/(1−a)} 为公比 a 的等比数列求通项。

**正文**：

由递推式求概率的通项时，常用**待定系数法**把递推式配成等比数列。\n\n**操作流程**（以甲、乙、丙三人打台球为例）\n1. 写出递推式：设第 $n$ 局有甲参与的概率为 $P_n$。若第 $n$ 局有甲参与，则第 $n+1$ 局有甲参与的概率为 $\dfrac{1}{2}$；若第 $n$ 局没有甲参与，则第 $n+1$ 局一定有甲参与，故 $P_{n+1}=\dfrac{1}{2}P_n+(1-P_n)$；\n2. 化简得 $P_{n+1}=-\dfrac{1}{2}P_n+1$，即 $P_{n+1}-\dfrac{2}{3}=-\dfrac{1}{2}\left(P_n-\dfrac{2}{3}\right)$；\n3. 由初始值 $P_1=1$ 得 $P_1-\dfrac{2}{3}=\dfrac{1}{3}$，故 $\left\{P_n-\dfrac{2}{3}\right\}$ 是首项为 $\dfrac{1}{3}$、公比为 $-\dfrac{1}{2}$ 的等比数列；\n4. 于是 $P_n=\dfrac{1}{3}\left(-\dfrac{1}{2}\right)^{n-1}+\dfrac{2}{3}$。\n\n同类地，若记第 $n$ 局有丙参与的概率为 $Q_n$，由 $Q_{n+1}=\dfrac{1}{2}Q_n+(1-Q_n)$ 得 $Q_n=-\dfrac{2}{3}\left(-\dfrac{1}{2}\right)^{n-1}+\dfrac{2}{3}$，则第 $n$ 局是甲、乙对打的概率为 $1-Q_n$。\n\n**要点**：形如 $P_{n+1}=aP_n+b$（$a\neq 1$）的递推式，都可配成 $\left\{P_n-\dfrac{b}{1-a}\right\}$ 为公比 $a$ 的等比数列。

**边界**：

待定系数法中要求 $a\neq 1$，否则数列为等差而非等比。求出的概率通项必须用初始条件检验，且要保证 $0\le P_n\le 1$。注意“有甲参与”与“甲、乙对打”是两个不同的事件，最后要用 $1-Q_n$ 转换。

**适用**：

概率递推得到一次递推式后求第 n 次概率的通项。

### 材料 3：[ext-mat-a0a6f314bb-001] 概率递推问题的构造数列通法

**摘要**：

第 n 次结果只由前一次结果决定时，用全概率公式列出递推式，再用待定系数法构造等比数列求通项。

**正文**：

### 一、识别特征\n第 $n$ 次操作的结果受第 $n-1$ 次结果影响，可以类比数列的递推公式来处理，例如“甲、乙、丙相互传球，求若干次传球后球在甲手中的概率”“第 $n$ 代开红花或黄花的概率”等。\n### 二、两步通法\n1. **按上一次的两种结果分裂样本空间**，套全概率公式列出递推式。如从第 $n$ 个盒子取红球记为 $A_{n}$，则 $P(A_{n})=P(A_{n-1})P(A_{n}|A_{n-1})+P(\bar{A}_{n-1})P(A_{n}|\bar{A}_{n-1})$，整理得 $P(A_{n})=\dfrac{2}{3}P(A_{n-1})+\dfrac{1}{3}$。\n2. **待定系数法构造等比数列**。形如 $P(A_{n})=\lambda P(A_{n-1})+\mu$（$\lambda\ne 1$）时设 $P(A_{n})+x=\lambda[P(A_{n-1})+x]$，比较系数得 $x=\dfrac{\mu}{\lambda-1}$，则 $\{P(A_{n})+x\}$ 是公比为 $\lambda$ 的等比数列。上例中比较得 $-\dfrac{2}{3}x=\dfrac{1}{3}$，即 $x=-\dfrac{1}{2}$，故 $\left\{P(A_{n})-\dfrac{1}{2}\right\}$ 是首项 $\dfrac{1}{6}$、公比 $\dfrac{1}{3}$ 的等比数列，$P(A_{n})=\dfrac{1}{2}\times\left(\dfrac{1}{3}\right)^{n}+\dfrac{1}{2}$。\n### 三、两状态互斥的情形\n“第 $n$ 局有甲参与的概率 $P_{n}$”这类问题先写 $P_{n+1}=\dfrac{1}{2}P_{n}+(1-P_{n})$，再化为 $P_{n+1}-\dfrac{2}{3}=-\dfrac{1}{2}\left(P_{n}-\dfrac{2}{3}\right)$ 求通项；若还要限制具体对手（如“第 $n$ 局甲、乙对打”），另设一个概率 $Q_{n}$ 与原递推联立求解。

**边界**：

递推式中的 $P(A_{n})$ 必须是同一事件在不同轮次下的概率；构造等比数列后要用首项检验（如 $P_{1}-\dfrac{1}{2}\ne 0$ 才能作为首项）；$\lambda=1$ 时不能这样构造，应由 $P(A_{n})-P(A_{n-1})=\mu$ 按等差数列处理。

**适用**：

传球、取球、盒子倒球、比赛轮换等“本次结果受上一次影响”的概率题的求通项与求第 n 次概率。

### 材料 4：[ext-mat-91e0c2ace8-135] 概率结合数列模型的三步法

**摘要**：

第 n 次操作影响第 n+1 次操作的问题，先设 P_n、由全概率公式列出递推式，再用构造等比数列求通项。

**正文**：

对于甲、乙、丙三人相互传球、求若干次后球在甲手里的概率这类问题，其特征是第 n 次操作的情况会影响第 n+1 次操作的情况（马尔可夫链的特点），可按以下三步处理：\n\n- **第一步** 设出第 n 次操作后需要求解的概率 $P_n$；\n- **第二步** 根据题目中的条件得到概率数列 $\{P_n\}$ 所满足的递推关系式；\n- **第三步** 通过数列递推关系式求通项或数列求和解决问题。\n\n### 关键：由全概率公式列递推式\n理清第 n+1 次操作与第 n 次操作的关系，根据全概率公式列出数列递推式，再用数列递推公式的相关方法求解。即由题意得出\n$P_{n+1}=pP_n+q$（$p\ne 1$），\n构造等比数列 $P_{n+1}+\lambda=p(P_n+\lambda)$，其中 $\lambda=\frac{q}{p-1}$，则 $\{P_n+\lambda\}$ 是以 $P_1+\lambda$ 为首项、p 为公比的等比数列，求出通项公式即可得出所求概率。\n\n### 算例\n正三棱柱中蚂蚁从上底面某顶点出发，每次沿棱爬到相邻顶点（三个方向等可能），求爬行 10 次后仍在上底面的概率：设爬行 n 次后仍在上底面的概率为 $P_n$，则在下底面的概率为 $1-P_n$。因为在上底面时再爬 1 次回到上底面的概率为 $\frac{2}{3}$，在下底面时再爬 1 次到上底面的概率为 $\frac{1}{3}$，故\n$P_{n+1}=P_n\times\frac{2}{3}+(1-P_n)\times\frac{1}{3}=\frac{1}{3}P_n+\frac{1}{3}$，\n从而 $P_{n+1}-\frac{1}{2}=\frac{1}{3}(P_n-\frac{1}{2})$，故 $\{P_n-\frac{1}{2}\}$ 是以 $\frac{1}{6}$ 为首项、$\frac{1}{3}$ 为公比的等比数列，得 $P_n=\frac{1}{2}(\frac{1}{3})^n+\frac{1}{2}$，代入 n=10 即可。

**边界**：

必须先明确状态（如在上底面/在下底面）并写出两类状态间的转移概率，且两类概率之和为 1；递推式的首项要单独求出（$P_1$ 不能由递推式得到）；构造等比数列时 λ 的公式是 $\frac{q}{p-1}$，$(p-1)$ 出现在分母要求 $p\ne 1$（$p=1$ 时是等差数列，另行处理）；求出的通项要按题目所求的 n 代入。

**适用**：

传球、爬行、投篮等状态转移的概率问题（求若干次后处于某状态的概率）。

### 材料 5：[ext-mat-6bb5e3bff6-001] 概率与数列综合：建立概率递推关系

**摘要**：

把第 n 次的概率按上一次的两种情形用全概率公式表示为第 n−1 次概率的函数，再用数列方法求通项或证不等式。

**正文**：

题型特征：题目描述一个反复进行的随机试验（抛掷、抽取、选择等），要求求第 $n$ 次发生某事件的概率、证明概率不等式或求通项。概率、统计与数列的结合是高考创新题的重要来源。\n\n建模步骤：\n（1）设第 $n$ 次发生目标事件的概率为 $p_n$（或记为 $P_n$）；\n（2）按第 $n-1$ 次的两种可能情形分类，用全概率公式写出 $p_n$ 与 $p_{n-1}$ 的关系式，把“第 $n$ 次的概率”表示为“第 $n-1$ 次概率”的函数，这一步是核心；\n（3）整理递推式：若化成 $p_n=ap_{n-1}+b$ 的形式，则用构造法把它化为等比数列求通项；若化为 $p_{n+1}-p_n$ 与 $p_n$ 的关系，则考虑用单调性或不等式处理；\n（4）用数列的方法求通项、证明不等式或求最值。\n\n典型模型：抛硬币或抛正四面体中“出现偶数次”的概率、每天在两种套餐中选择、袋中球的置换等，都属于这类状态转移问题。

**边界**：

建立递推式时要把上一次的所有情形讨论完整，漏掉一种情形会导致递推式错误；第一次（初始）概率要单独给出；不放回操作或有额外条件时转移概率会改变，需要重新分析。

**适用**：

反复进行的随机试验中求第 n 次事件的概率；证明概率的不等式或单调性；抛掷、选择、置换类创新题。

### 材料 6：[ext-mat-2561b596d8-003] 概率与数列结合的四类递推模型

**摘要**：

概率与数列的综合题常以递推形式出现，主要有四种递推结构，需先建立递推关系再转化为数列求通项。

**正文**：

在概率与统计问题中，经常出现概率与数列综合考查的题目，一般以压轴题的形式出现，主要有四种类型：①$a_n=pa_{n-1}+q$ 型；②$a_{n+1}=pa_n+f(n)$ 型；③$a_{n+1}=a_nf(n)$ 型；④$a_{n+1}=pa_n+qa_{n-1}$ 型。\n处理思路：先把第 $n$ 次试验后某事件发生的概率记为 $P_n$，依据试验规则分析第 $n$ 次与第 $n-1$ 次（有时还与第 $n-2$ 次）概率之间的关系，建立递推式；再把递推式对应到上述四种结构之一，用构造法、累加法或特征根法求出通项，进而回答概率问题。\n识别递推结构的关键：看相邻两项之间是“乘系数加常数”“乘系数加关于 $n$ 的函数”，还是“与前两项都有关”，据此选择求通项的方法。

**边界**：

建立递推式时要写清“第 n 次”与“第 n-1 次”的状态定义，初始项由题目给定的首次情形确定；递推式要求相邻两次之间的转移方式不变，若规则随次数变化则需分段讨论。

**适用**：

传球、投篮、抽奖等重复试验的概率问题；概率压轴题中求 Pn 的递推式、通项或取值范围。
