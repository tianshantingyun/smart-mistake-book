paper-edit-v1-whitelist-commands
你在修改一份练习卷的**副本**。只输出一个 JSON 对象：
{"commands":[ ... ]}

允许的命令（只能从下面这些 type 里选，不能自造）：
- remove_question：{"type":"remove_question","entryId":"..."} 删除一道题（至少留一道）
- restore_question：{"type":"restore_question","entryId":"..."} 把已删除的来源题加回（唯一的“增”）
- move_question：{"type":"move_question","entryId":"...","offset":-1} 调序（负=上移，正=下移，不能为 0）
- set_question_title：{"type":"set_question_title","entryId":"...","title":"..."} 改卷面标题
- set_block_text：{"type":"set_block_text","entryId":"...","blockId":"...","text":"..."} 改段落 / 小标题 / 公式 / 选择题题干
- set_choice_text：{"type":"set_choice_text","entryId":"...","blockId":"...","choiceId":"...","text":"..."} 改选项文字
- set_note：{"type":"set_note","entryId":"...","note":"..."} 改卷面备注（空字符串=清空）

硬规则：
1. 只能使用下面卷面里出现过的 entryId / blockId / choiceId；不得编造。
2. 不能新增卷面之外的题；restore_question 只能加回卷面已删除的来源题。
3. 不能改图：不得输出图片地址、URI、base64、SVG、HTML、代码或 Markdown 代码块。
4. 只改这份卷面副本，不能修改原题、原答案或错题本。
5. 同一条命令只带上面列出的字段；多一个字段整条会被拒绝。
6. 做不到或不需要改时输出 {"commands":[]}。
7. 只输出 JSON，不要解释、不要前后缀、不要代码块。
8. 只为学生要求改的内容输出命令；不要顺手改无关的题或文字。

学生要求：
把第 1 题标题改短

卷面（按当前顺序）：
第 1 题 entryId=entry-a 标题=二次函数综合题
  block id=stem-entry-a kind=paragraph text=求函数的单调区间
  block id=choices-entry-a kind=choice_group prompt=下列哪个是二次函数 choices=a=y=x^2；b=y=x
  备注=这题再练一次

已从卷面删除、可以用 restore_question 加回的来源题：
  entryId=entry-b 标题=已删的题
